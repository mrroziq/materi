BAGIAN IX / DATA SCIENCE

SQL dan Database

SQL (Structured Query Language) adalah bahasa yang digunakan untuk mengelola dan mengambil data dari database relasional. Dalam Data Science, SQL membantu mengumpulkan, memfilter, menggabungkan, dan meringkas data sebelum dianalisis menggunakan Python atau perangkat lainnya.

1. Konsep Database Relasional

Database adalah kumpulan data yang disimpan secara terorganisasi. Database relasional menyimpan data dalam bentuk tabel yang terdiri atas baris dan kolom. Hubungan antartabel dibangun menggunakan atribut atau kolom yang saling berkaitan.

Contoh tabel pelanggan:

id_pelanggan nama kota
1 Andi Semarang
2 Budi Yogyakarta
3 Citra Semarang

Setiap baris merepresentasikan satu pelanggan, sedangkan setiap kolom menyimpan atribut tertentu. Contoh sistem database relasional antara lain PostgreSQL, MySQL, SQLite, dan Microsoft SQL Server.

Istilah penting

  • Database: kumpulan data yang terorganisasi.
  • Tabel: struktur data yang terdiri atas baris dan kolom.
  • Record: satu baris data dalam tabel.
  • Field: atribut atau kolom dalam tabel.
  • Schema: struktur yang mendefinisikan tabel, kolom, tipe data, dan relasi.

Dalam Data Science, database relasional sering digunakan untuk menyimpan transaksi penjualan, informasi pelanggan, data keuangan, dan catatan aktivitas.

2. Tabel, Primary Key, dan Foreign Key

Primary key adalah kolom atau kombinasi kolom yang mengidentifikasi setiap baris secara unik. Nilainya tidak boleh duplikat dan tidak boleh NULL.

Foreign key adalah kolom yang merujuk pada primary key atau kandidat kunci yang memenuhi syarat pada tabel lain. Foreign key digunakan untuk menjaga konsistensi hubungan antartabel.

Tabel pelanggan

CREATE TABLE pelanggan (
    id_pelanggan INTEGER PRIMARY KEY,
    nama VARCHAR(100),
    kota VARCHAR(100)
);

Tabel transaksi

CREATE TABLE transaksi (
    id_transaksi INTEGER PRIMARY KEY,
    id_pelanggan INTEGER,
    tanggal DATE,
    total DECIMAL(12, 2),
    FOREIGN KEY (id_pelanggan)
        REFERENCES pelanggan(id_pelanggan)
);

Pada contoh tersebut, id_pelanggan menjadi primary key di tabel pelanggan dan foreign key di tabel transaksi. Dengan demikian, transaksi dapat dihubungkan dengan pelanggan yang sesuai.

Hubungan satu-ke-banyak (one-to-many) terjadi ketika satu pelanggan dapat memiliki banyak transaksi, tetapi setiap transaksi merujuk pada satu pelanggan.

3. SELECT, WHERE, dan ORDER BY

Perintah SELECT digunakan untuk mengambil kolom dari tabel. WHERE menyaring baris berdasarkan kondisi, sedangkan ORDER BY mengurutkan hasil query.

Mengambil semua kolom

SELECT *
FROM pelanggan;

Memilih kolom tertentu

SELECT nama, kota
FROM pelanggan;

Menyaring data

SELECT *
FROM pelanggan
WHERE kota = 'Semarang';

Operator yang sering digunakan dalam kondisi WHERE:

  • =, <>: sama dengan dan tidak sama dengan.
  • >, <, >=, <=: perbandingan numerik.
  • AND, OR, NOT: menggabungkan atau membalik kondisi.
  • IN: memeriksa keanggotaan dalam sekumpulan nilai.
  • BETWEEN: memeriksa rentang nilai.
  • LIKE: mencocokkan pola teks.
  • IS NULL: memeriksa nilai yang tidak tersedia.

Menggabungkan kondisi dan pengurutan

SELECT nama, kota
FROM pelanggan
WHERE kota IN ('Semarang', 'Yogyakarta')
ORDER BY nama ASC;

ASC berarti urutan menaik, sedangkan DESC berarti urutan menurun.

Membatasi jumlah hasil

SELECT *
FROM transaksi
ORDER BY total DESC
LIMIT 5;

Query tersebut mengambil lima transaksi dengan nilai total terbesar. LIMIT tersedia di beberapa sistem seperti PostgreSQL, MySQL, dan SQLite; sistem database lain dapat menggunakan sintaks berbeda.

4. Agregasi dengan GROUP BY

Agregasi digunakan untuk meringkas banyak baris menjadi informasi statistik. SQL menyediakan fungsi agregasi seperti:

  • COUNT(): menghitung jumlah baris atau nilai yang tidak NULL.
  • SUM(): menjumlahkan nilai.
  • AVG(): menghitung rata-rata.
  • MIN(): mencari nilai minimum.
  • MAX(): mencari nilai maksimum.

Menghitung jumlah transaksi setiap pelanggan

SELECT
    id_pelanggan,
    COUNT(*) AS jumlah_transaksi,
    SUM(total) AS total_belanja,
    AVG(total) AS rata_rata_transaksi
FROM transaksi
GROUP BY id_pelanggan;

GROUP BY mengelompokkan baris berdasarkan id_pelanggan. Fungsi agregasi kemudian dihitung untuk setiap kelompok.

Menggunakan HAVING

SELECT
    id_pelanggan,
    SUM(total) AS total_belanja
FROM transaksi
GROUP BY id_pelanggan
HAVING SUM(total) > 1000000;

HAVING menyaring hasil pengelompokan. Perbedaannya, WHERE menyaring baris sebelum agregasi, sedangkan HAVING menyaring kelompok setelah agregasi.

Urutan logis pemrosesan query secara umum adalah:

FROM / JOIN
WHERE
GROUP BY
HAVING
SELECT
ORDER BY
LIMIT

5. JOIN dan Subquery

JOIN menggabungkan data dari beberapa tabel berdasarkan kondisi hubungan tertentu.

INNER JOIN

Mengambil baris yang memiliki pasangan pada kedua tabel. 

SELECT
    p.nama,
    t.id_transaksi,
    t.total
FROM pelanggan AS p
INNER JOIN transaksi AS t
    ON p.id_pelanggan = t.id_pelanggan;

LEFT JOIN

Mengambil seluruh baris dari tabel kiri dan data pasangan dari tabel kanan jika tersedia. Jika tidak ada pasangan, kolom dari tabel kanan akan bernilai NULL. 

SELECT
    p.nama,
    t.id_transaksi,
    t.total
FROM pelanggan AS p
LEFT JOIN transaksi AS t
    ON p.id_pelanggan = t.id_pelanggan;

Jenis JOIN lain meliputi RIGHT JOIN dan FULL OUTER JOIN. Dukungan sintaks bergantung pada sistem database yang digunakan.

Subquery

Subquery adalah query yang berada di dalam query lain. Subquery berguna ketika analisis membutuhkan hasil perhitungan atau pemilihan data dari query sebelumnya. 

SELECT *
FROM transaksi
WHERE total > (
    SELECT AVG(total)
    FROM transaksi
);

Query tersebut mengambil transaksi dengan nilai di atas rata-rata seluruh transaksi.

Subquery dengan IN

SELECT nama
FROM pelanggan
WHERE id_pelanggan IN (
    SELECT id_pelanggan
    FROM transaksi
    GROUP BY id_pelanggan
    HAVING SUM(total) > 1000000
);

Query tersebut mencari pelanggan yang total belanjanya melebihi satu juta.

6. Common Table Expressions (CTE)

Common Table Expression atau CTE adalah hasil query sementara yang diberi nama menggunakan kata kunci WITH. CTE membantu membuat query kompleks lebih mudah dibaca dan disusun menjadi beberapa tahap.

Contoh CTE

WITH ringkasan_pelanggan AS (
    SELECT
        id_pelanggan,
        COUNT(*) AS jumlah_transaksi,
        SUM(total) AS total_belanja
    FROM transaksi
    GROUP BY id_pelanggan
)
SELECT *
FROM ringkasan_pelanggan
WHERE total_belanja > 1000000
ORDER BY total_belanja DESC;

Tahap pertama menghasilkan ringkasan transaksi per pelanggan. Tahap kedua menyaring pelanggan berdasarkan total belanja dan mengurutkan hasilnya.

CTE dibandingkan subquery

  • Subquery: cocok untuk perhitungan bersarang yang relatif sederhana.
  • CTE: membantu memisahkan query panjang menjadi tahap-tahap bernama.
  • CTE rekursif: dapat digunakan untuk struktur bertingkat atau relasi hierarkis pada database yang mendukungnya.

CTE bukan berarti data selalu disimpan secara permanen. Umumnya, CTE hanya berlaku selama satu pernyataan SQL.

7. Window Functions

Window function melakukan perhitungan pada sekumpulan baris yang berhubungan dengan baris saat ini, tanpa menggabungkan semua baris menjadi satu baris seperti agregasi biasa dengan GROUP BY.

Klausa OVER() mendefinisikan jendela perhitungan. PARTITION BY membagi data menjadi kelompok, sedangkan ORDER BY menentukan urutan baris dalam kelompok.

Memberi peringkat transaksi

SELECT
    id_pelanggan,
    id_transaksi,
    total,
    ROW_NUMBER() OVER (
        PARTITION BY id_pelanggan
        ORDER BY total DESC
    ) AS peringkat_transaksi
FROM transaksi;

ROW_NUMBER() memberi nomor urut transaksi untuk setiap pelanggan berdasarkan nilai total terbesar.

RANK dan DENSE_RANK

SELECT
    id_transaksi,
    total,
    RANK() OVER (
        ORDER BY total DESC
    ) AS peringkat,
    DENSE_RANK() OVER (
        ORDER BY total DESC
    ) AS peringkat_padat
FROM transaksi;

Jika beberapa transaksi memiliki nilai yang sama, RANK() memberikan peringkat yang sama dan dapat melewati nomor peringkat berikutnya. DENSE_RANK() memberikan peringkat yang sama tanpa melewati nomor berikutnya.

Menghitung total kumulatif

SELECT
    tanggal,
    total,
    SUM(total) OVER (
        ORDER BY tanggal
        ROWS BETWEEN UNBOUNDED PRECEDING
        AND CURRENT ROW
    ) AS total_kumulatif
FROM transaksi;

Total kumulatif membantu melihat perkembangan nilai transaksi dari waktu ke waktu. Jika terdapat beberapa transaksi pada tanggal yang sama, tambahkan kolom pengurutan unik seperti id_transaksi untuk membuat urutan lebih konsisten.

Fungsi window yang umum

  • ROW_NUMBER(): memberi nomor urut setiap baris.
  • RANK() dan DENSE_RANK(): menentukan peringkat.
  • LAG(): mengambil nilai dari baris sebelumnya.
  • LEAD(): mengambil nilai dari baris berikutnya.
  • SUM() OVER(): menghitung jumlah dalam jendela.
  • AVG() OVER(): menghitung rata-rata dalam jendela.

8. Query untuk Analisis Data

SQL bukan hanya digunakan untuk mengambil data. SQL juga dapat melakukan analisis awal untuk memahami perilaku pelanggan, tren penjualan, performa produk, dan pola transaksi.

A. Total penjualan per kota

SELECT
    p.kota,
    COUNT(t.id_transaksi) AS jumlah_transaksi,
    SUM(t.total) AS total_penjualan,
    AVG(t.total) AS rata_rata_transaksi
FROM pelanggan AS p
JOIN transaksi AS t
    ON p.id_pelanggan = t.id_pelanggan
GROUP BY p.kota
ORDER BY total_penjualan DESC;

Analisis ini membandingkan jumlah transaksi dan nilai penjualan berdasarkan kota pelanggan.

B. Tren penjualan bulanan

SELECT
    EXTRACT(YEAR FROM tanggal) AS tahun,
    EXTRACT(MONTH FROM tanggal) AS bulan,
    COUNT(*) AS jumlah_transaksi,
    SUM(total) AS total_penjualan
FROM transaksi
GROUP BY
    EXTRACT(YEAR FROM tanggal),
    EXTRACT(MONTH FROM tanggal)
ORDER BY tahun, bulan;

Query ini menggunakan sintaks PostgreSQL. Fungsi ekstraksi tanggal dapat berbeda pada MySQL, SQLite, dan sistem database lainnya. Hasilnya dapat digunakan untuk membuat grafik tren penjualan.

C. Pelanggan dengan nilai transaksi terbesar

SELECT
    p.id_pelanggan,
    p.nama,
    SUM(t.total) AS total_belanja
FROM pelanggan AS p
JOIN transaksi AS t
    ON p.id_pelanggan = t.id_pelanggan
GROUP BY p.id_pelanggan, p.nama
ORDER BY total_belanja DESC
LIMIT 10;

Hasilnya dapat digunakan untuk mengenali pelanggan bernilai tinggi.

D. Membandingkan transaksi dengan rata-rata

SELECT
    id_transaksi,
    tanggal,
    total,
    ROUND(
        total - (SELECT AVG(total) FROM transaksi),
        2
    ) AS selisih_dari_rata_rata
FROM transaksi
ORDER BY selisih_dari_rata_rata DESC;

Nilai selisih positif menunjukkan transaksi berada di atas rata-rata, sedangkan nilai negatif menunjukkan transaksi berada di bawah rata-rata.

E. Menghitung pertumbuhan penjualan bulanan

WITH penjualan_bulanan AS (
    SELECT
        DATE_TRUNC('month', tanggal) AS bulan,
        SUM(total) AS penjualan
    FROM transaksi
    GROUP BY DATE_TRUNC('month', tanggal)
),
perbandingan AS (
    SELECT
        bulan,
        penjualan,
        LAG(penjualan) OVER (
            ORDER BY bulan
        ) AS penjualan_bulan_lalu
    FROM penjualan_bulanan
)
SELECT
    bulan,
    penjualan,
    penjualan_bulan_lalu,
    ROUND(
        100.0 * (penjualan - penjualan_bulan_lalu)
        / NULLIF(penjualan_bulan_lalu, 0),
        2
    ) AS pertumbuhan_persen
FROM perbandingan
ORDER BY bulan;

Contoh ini menggunakan PostgreSQL. DATE_TRUNC() membuat tanggal awal bulan, LAG() mengambil penjualan bulan sebelumnya, dan NULLIF() mencegah pembagian dengan nol.

Pertumbuhan dihitung dengan rumus:

\[ \text{Pertumbuhan} = \frac{\text{Penjualan sekarang} - \text{Penjualan sebelumnya}} {\text{Penjualan sebelumnya}} \times 100\% \]

Jika penjualan bulan sebelumnya bernilai nol atau tidak tersedia, pertumbuhan persentase tidak dapat dihitung secara langsung.

9. Integrasi SQL dengan Python

SQL digunakan untuk mengambil dan meringkas data dari database, sedangkan Python digunakan untuk analisis lanjutan, visualisasi, statistik, dan pemodelan Machine Learning.

Untuk database SQLite, Python menyediakan modul bawaan sqlite3. Data hasil query dapat dibaca sebagai DataFrame menggunakan Pandas.

A. Membaca data SQLite dengan Pandas

import sqlite3
import pandas as pd

# Membuka atau membuat database SQLite
conn = sqlite3.connect("penjualan.db")

query = """
SELECT
    id_pelanggan,
    COUNT(*) AS jumlah_transaksi,
    SUM(total) AS total_belanja
FROM transaksi
GROUP BY id_pelanggan
"""

df = pd.read_sql_query(query, conn)

print(df.head())

conn.close()

Fungsi pd.read_sql_query() menjalankan query dan mengembalikan hasilnya sebagai DataFrame.

B. Mengirim parameter dengan aman

Hindari menyusun query menggunakan penggabungan string dari input pengguna. Gunakan parameter query agar nilai input diperlakukan sebagai data, bukan sebagai bagian dari sintaks SQL. 

import sqlite3
import pandas as pd

kota = "Semarang"

with sqlite3.connect("penjualan.db") as conn:
    query = """
    SELECT
        p.nama,
        p.kota,
        t.tanggal,
        t.total
    FROM pelanggan AS p
    JOIN transaksi AS t
        ON p.id_pelanggan = t.id_pelanggan
    WHERE p.kota = ?
    ORDER BY t.tanggal
    """

    df = pd.read_sql_query(
        query,
        conn,
        params=(kota,)
    )

print(df.head())

Pada SQLite, tanda ? digunakan sebagai placeholder parameter. Sistem database lain dapat menggunakan bentuk placeholder yang berbeda.

C. Analisis lanjutan menggunakan Pandas

import matplotlib.pyplot as plt

df["tanggal"] = pd.to_datetime(df["tanggal"])

penjualan_harian = (
    df.groupby(df["tanggal"].dt.date)["total"]
      .sum()
)

penjualan_harian.plot(
    kind="line",
    figsize=(10, 5),
    marker="o"
)

plt.title("Tren Penjualan Harian")
plt.xlabel("Tanggal")
plt.ylabel("Total Penjualan")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

Setelah data diambil dari database, Pandas dapat digunakan untuk melakukan transformasi dan agregasi tambahan. Matplotlib kemudian membantu menyajikan pola data secara visual.

D. Alur kerja SQL dan Python

  1. Hubungkan Python dengan database.
  2. Tulis query untuk mengambil data yang relevan.
  3. Filter dan agregasikan data sedekat mungkin dengan sumbernya.
  4. Masukkan hasil query ke DataFrame.
  5. Lakukan pembersihan dan analisis lanjutan menggunakan Pandas.
  6. Buat visualisasi atau gunakan data sebagai masukan model Machine Learning.

Untuk database besar, mengambil hanya kolom dan baris yang diperlukan dapat menghemat memori serta mempercepat proses analisis.

10. Mini Project: Analisis Penjualan dengan SQL dan Python

Pada proyek ini, kamu akan menganalisis transaksi penjualan dari database relasional dan memvisualisasikan hasilnya menggunakan Python.

Struktur data

Tabel pelanggan:

id_pelanggan nama kota
1 Andi Semarang
2 Budi Yogyakarta
3 Citra Semarang

Tabel transaksi:

id_transaksi id_pelanggan tanggal total
101 1 2026-01-05 250000
102 2 2026-01-07 400000
103 1 2026-02-02 350000
104 3 2026-02-10 500000
105 2 2026-02-15 150000

Langkah 1: Membuat database dan tabel

import sqlite3

conn = sqlite3.connect("penjualan.db")

conn.executescript("""
CREATE TABLE IF NOT EXISTS pelanggan (
    id_pelanggan INTEGER PRIMARY KEY,
    nama TEXT NOT NULL,
    kota TEXT
);

CREATE TABLE IF NOT EXISTS transaksi (
    id_transaksi INTEGER PRIMARY KEY,
    id_pelanggan INTEGER NOT NULL,
    tanggal TEXT NOT NULL,
    total REAL NOT NULL,
    FOREIGN KEY (id_pelanggan)
        REFERENCES pelanggan(id_pelanggan)
);
""")

conn.commit()

Langkah 2: Memasukkan data contoh

pelanggan = [
    (1, "Andi", "Semarang"),
    (2, "Budi", "Yogyakarta"),
    (3, "Citra", "Semarang")
]

transaksi = [
    (101, 1, "2026-01-05", 250000),
    (102, 2, "2026-01-07", 400000),
    (103, 1, "2026-02-02", 350000),
    (104, 3, "2026-02-10", 500000),
    (105, 2, "2026-02-15", 150000)
]

conn.executemany(
    "INSERT OR IGNORE INTO pelanggan VALUES (?, ?, ?)",
    pelanggan
)

conn.executemany(
    "INSERT OR IGNORE INTO transaksi VALUES (?, ?, ?, ?)",
    transaksi
)

conn.commit()

Contoh ini memakai INSERT OR IGNORE agar data dengan primary key yang sudah ada tidak dimasukkan kembali pada saat skrip dijalankan ulang. Untuk proyek nyata, aturan penanganan duplikasi sebaiknya ditentukan secara eksplisit.

Langkah 3: Menganalisis penjualan per kota

import pandas as pd

query = """
SELECT
    p.kota,
    COUNT(t.id_transaksi) AS jumlah_transaksi,
    SUM(t.total) AS total_penjualan,
    AVG(t.total) AS rata_rata_transaksi
FROM pelanggan AS p
JOIN transaksi AS t
    ON p.id_pelanggan = t.id_pelanggan
GROUP BY p.kota
ORDER BY total_penjualan DESC;
"""

df_kota = pd.read_sql_query(query, conn)
print(df_kota)

Berdasarkan data contoh, Semarang menghasilkan penjualan sebesar Rp1.100.000 dari tiga transaksi, sedangkan Yogyakarta menghasilkan Rp550.000 dari dua transaksi.

Langkah 4: Menyimpan hasil analisis

df_kota.to_csv(
    "hasil_analisis_penjualan.csv",
    index=False
)

conn.close()

Hasil analisis dapat disimpan sebagai CSV, kemudian digunakan dalam laporan, dashboard, atau proses analisis berikutnya.

Ringkasan

  • Database relasional menyimpan data dalam tabel yang saling berhubungan.
  • Primary key mengidentifikasi baris secara unik, sedangkan foreign key menghubungkan tabel.
  • SELECT, WHERE, dan ORDER BY digunakan untuk mengambil, menyaring, dan mengurutkan data.
  • GROUP BY dan fungsi agregasi membantu membuat ringkasan statistik.
  • JOIN dan subquery menggabungkan atau mengambil data dari beberapa query.
  • CTE membuat query kompleks lebih terstruktur.
  • Window function memungkinkan peringkat, perbandingan antarbaris, dan perhitungan kumulatif.
  • SQL dapat dipadukan dengan Python untuk membangun alur analisis data yang efisien.
