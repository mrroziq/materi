Deep Learning

Deep learning adalah bagian dari machine learning yang menggunakan jaringan saraf dengan banyak lapisan untuk mempelajari pola dari data. Metode ini banyak digunakan dalam pengenalan gambar, pemrosesan bahasa alami, pengenalan suara, dan analisis data kompleks lainnya.

1. Dasar Jaringan Saraf Tiruan

Jaringan saraf tiruan atau Artificial Neural Network (ANN) merupakan model komputasi yang tersusun dari unit-unit pemrosesan yang disebut neuron. Setiap neuron menerima masukan, melakukan perhitungan, lalu menghasilkan keluaran.

Secara sederhana, jaringan saraf memiliki tiga jenis lapisan:

  • Input layer: menerima fitur dari data.
  • Hidden layer: mempelajari representasi atau pola dari data.
  • Output layer: menghasilkan prediksi model.

Jaringan dengan banyak hidden layer memungkinkan model mempelajari representasi bertingkat. Misalnya, pada pengenalan gambar, lapisan awal dapat mempelajari pola sederhana seperti tepi, sedangkan lapisan berikutnya dapat mengenali bentuk yang lebih kompleks.

Berbeda dari model linear sederhana, jaringan saraf dapat mempelajari hubungan nonlinier melalui penggunaan activation function.

2. Neuron, Layer, dan Activation Function

Sebuah neuron menghitung kombinasi linear dari input, bobot, dan bias, kemudian menerapkan fungsi aktivasi.

\[ z=\sum_{i=1}^{n}w_i x_i+b \] \[ a=f(z) \]

Keterangan:

  • \(x_i\): nilai input ke-\(i\).
  • \(w_i\): bobot yang dipelajari model.
  • \(b\): bias.
  • \(z\): hasil kombinasi linear.
  • \(f\): fungsi aktivasi.
  • \(a\): keluaran neuron setelah aktivasi.

Fungsi aktivasi yang umum

Sigmoid

\[ \sigma(z)=\frac{1}{1+e^{-z}} \]

Menghasilkan nilai antara 0 dan 1. Sering digunakan pada output klasifikasi biner untuk menghasilkan probabilitas.

ReLU (Rectified Linear Unit)

\[ \operatorname{ReLU}(z)=\max(0,z) \]

Menghasilkan nol untuk input negatif dan mempertahankan nilai input positif. ReLU banyak digunakan pada hidden layer.

Softmax

\[ \operatorname{softmax}(z_i)= \frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}} \]

Mengubah sekumpulan skor menjadi distribusi probabilitas antarkelas. Softmax lazim digunakan pada output klasifikasi multikelas.

3. Forward Propagation

Forward propagation adalah proses mengalirkan input melalui lapisan-lapisan jaringan hingga menghasilkan prediksi.

Untuk jaringan dengan satu hidden layer, perhitungannya dapat ditulis sebagai:

\[ \mathbf{z}^{(1)}=W^{(1)}\mathbf{x}+\mathbf{b}^{(1)} \] \[ \mathbf{a}^{(1)}=f(\mathbf{z}^{(1)}) \] \[ \mathbf{z}^{(2)}=W^{(2)}\mathbf{a}^{(1)}+\mathbf{b}^{(2)} \] \[ \hat{\mathbf{y}}=g(\mathbf{z}^{(2)}) \]

Matriks \(W\) berisi bobot, \(\mathbf{b}\) berisi bias, dan fungsi \(f\) serta \(g\) merupakan fungsi aktivasi pada lapisan terkait.

Contoh sederhana menggunakan Python dan NumPy: 

import numpy as np

x = np.array([0.5, 0.8])

W1 = np.array([
    [0.2, 0.4],
    [0.7, 0.3]
])
b1 = np.array([0.1, 0.2])

W2 = np.array([
    [0.6, 0.9]
])
b2 = np.array([0.1])

z1 = W1 @ x + b1
a1 = np.maximum(0, z1)

z2 = W2 @ a1 + b2
output = 1 / (1 + np.exp(-z2))

print("Aktivasi hidden layer:", a1)
print("Prediksi:", output)

Kode tersebut menggunakan ReLU pada hidden layer dan sigmoid pada output sehingga menghasilkan satu nilai antara 0 dan 1. Ini merupakan ilustrasi forward propagation, belum merupakan proses pelatihan lengkap.

4. Loss Function

Loss function mengukur seberapa jauh prediksi model dari nilai target. Selama pelatihan, model berusaha menemukan parameter yang meminimalkan loss.

Mean Squared Error (MSE)

Loss ini umum digunakan untuk regresi.

\[ \operatorname{MSE}= \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2 \]

Binary Cross-Entropy

Loss ini umum digunakan untuk klasifikasi biner dengan target 0 atau 1.

\[ L=-\frac{1}{n}\sum_{i=1}^{n} \left[ y_i\log(\hat{y}_i) +(1-y_i)\log(1-\hat{y}_i) \right] \]

Categorical Cross-Entropy

Untuk klasifikasi multikelas dengan target one-hot, loss dapat dihitung sebagai:

\[ L=-\sum_{k=1}^{K}y_k\log(\hat{y}_k) \]

Pemilihan loss function harus disesuaikan dengan jenis masalah, format target, dan keluaran model. Dalam implementasi, gunakan fungsi loss numerik stabil yang tersedia pada framework.

5. Backpropagation

Backpropagation adalah algoritma untuk menghitung gradien loss terhadap bobot dan bias pada setiap lapisan jaringan. Gradien tersebut digunakan oleh optimizer untuk memperbarui parameter.

Prosesnya dimulai dari loss pada output, lalu pengaruh kesalahan diteruskan kembali ke lapisan sebelumnya menggunakan aturan rantai dalam kalkulus.

Secara matematis, untuk parameter \(\theta\), kita menghitung:

\[ \frac{\partial L}{\partial \theta} \]

Jika parameter berupa bobot \(w\), gradien menunjukkan bagaimana perubahan kecil pada bobot tersebut memengaruhi loss.

Untuk neuron dengan:

\[ z=wx+b,\qquad a=f(z) \]

aturan rantai memberikan:

\[ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \frac{\partial a}{\partial z} \frac{\partial z}{\partial w} \]

Karena \(\frac{\partial z}{\partial w}=x\), gradien bobot bergantung pada input, turunan fungsi aktivasi, dan pengaruh keluaran terhadap loss.

Backpropagation menghitung gradien, sedangkan optimizer menggunakan gradien tersebut untuk memperbarui parameter. Keduanya merupakan bagian berbeda dari proses pelatihan.

6. Gradient Descent

Gradient descent merupakan metode optimasi yang memperbarui parameter ke arah yang diharapkan dapat menurunkan loss.

\[ \theta_{t+1}= \theta_t-\eta\nabla_{\theta}L(\theta_t) \]

Keterangan:

  • \(\theta_t\): parameter pada langkah ke-\(t\).
  • \(\eta\): learning rate.
  • \(\nabla_{\theta}L\): gradien loss terhadap parameter.

Learning rate menentukan ukuran langkah pembaruan. Jika terlalu besar, optimasi dapat melewati titik minimum atau menjadi tidak stabil. Jika terlalu kecil, pelatihan dapat berlangsung lambat.

Terdapat beberapa variasi gradient descent:

  • Batch gradient descent: menghitung gradien menggunakan seluruh data latih.
  • Stochastic gradient descent: memperbarui parameter menggunakan satu sampel pada setiap langkah.
  • Mini-batch gradient descent: menggunakan sebagian data pada setiap langkah dan umum dipakai dalam deep learning.

7. Optimizer

Optimizer adalah algoritma yang menggunakan gradien untuk memperbarui bobot dan bias. Optimizer yang berbeda memiliki strategi pembaruan parameter yang berbeda.

  • SGD: menggunakan gradien untuk memperbarui parameter; dapat dilengkapi momentum.
  • Momentum: memanfaatkan arah pembaruan sebelumnya untuk membantu pergerakan optimasi.
  • RMSprop: menyesuaikan ukuran langkah berdasarkan rata-rata bergerak kuadrat gradien.
  • Adam: menggabungkan estimasi rata-rata gradien dan kuadrat gradien untuk menyesuaikan pembaruan.

Contoh penggunaan optimizer Adam dengan PyTorch:

import torch
import torch.nn as nn

model = nn.Linear(4, 1)

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)

criterion = nn.MSELoss()

X = torch.randn(16, 4)
y = torch.randn(16, 1)

optimizer.zero_grad()

prediksi = model(X)
loss = criterion(prediksi, y)

loss.backward()
optimizer.step()

print("Loss:", loss.item())

Urutan pentingnya adalah menghapus gradien lama, menghitung prediksi dan loss, menghitung gradien melalui backward(), lalu memperbarui parameter dengan step().

8. Regularisasi dan Dropout

Jaringan saraf yang terlalu kompleks dapat mengalami overfitting, yaitu mempelajari pola khusus pada data latih yang tidak dapat digeneralisasi dengan baik ke data baru.

Weight Decay

Weight decay membatasi besarnya bobot model. Pada pendekatan L2 klasik, penalti dapat ditambahkan ke loss:

\[ L_{\text{total}}= L_{\text{data}}+\lambda\sum_j w_j^2 \]

Dropout

Dropout menonaktifkan sebagian aktivasi neuron secara acak selama pelatihan. Tujuannya membantu model tidak terlalu bergantung pada neuron tertentu. Saat evaluasi, dropout umumnya tidak menonaktifkan neuron dan framework menangani penyesuaian aktivasi yang diperlukan. 

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(20, 64),
    nn.ReLU(),
    nn.Dropout(p=0.3),
    nn.Linear(64, 32),
    nn.ReLU(),
    nn.Dropout(p=0.2),
    nn.Linear(32, 1)
)

model.train()
# Dropout aktif selama pelatihan

model.eval()
# Dropout dinonaktifkan selama evaluasi

Nilai dropout 0.3 berarti sekitar 30% aktivasi yang dikenai dropout dinonaktifkan secara acak pada setiap proses pelatihan. Dropout bukan jaminan menghilangkan overfitting; performanya tetap perlu dievaluasi pada data validasi.

9. Convolutional Neural Networks (CNN)

Convolutional Neural Network (CNN) merupakan arsitektur jaringan saraf yang banyak digunakan untuk data berbentuk grid, terutama gambar. CNN menggunakan filter atau kernel yang bergerak di atas input untuk mempelajari pola lokal.

Komponen umum CNN meliputi:

  • Convolution layer: mendeteksi pola lokal melalui filter.
  • Activation function: menambahkan kemampuan mempelajari hubungan nonlinier.
  • Pooling layer: merangkum informasi spasial dan dapat mengurangi ukuran representasi.
  • Fully connected layer: menggabungkan fitur untuk menghasilkan prediksi.

Misalnya, CNN untuk klasifikasi gambar dapat mempelajari pola tepi pada lapisan awal dan pola objek yang lebih kompleks pada lapisan berikutnya. 

import torch.nn as nn

cnn = nn.Sequential(
    nn.Conv2d(
        in_channels=1,
        out_channels=16,
        kernel_size=3,
        padding=1
    ),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),
    nn.Conv2d(
        in_channels=16,
        out_channels=32,
        kernel_size=3,
        padding=1
    ),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),
    nn.Flatten(),
    nn.Linear(32 * 7 * 7, 10)
)

Contoh ini mengasumsikan input berupa gambar grayscale berukuran 28 × 28 piksel. Dua operasi pooling berukuran 2 × 2 menghasilkan representasi spasial 7 × 7, sehingga lapisan linear menerima \(32\times7\times7\) fitur. Output berisi 10 skor kelas; untuk klasifikasi multikelas dengan CrossEntropyLoss, skor tersebut tidak perlu diubah menjadi probabilitas secara manual.

10. Recurrent Neural Networks (RNN)

Recurrent Neural Network (RNN) dirancang untuk memproses data berurutan, seperti teks, sinyal, atau deret waktu. RNN membawa hidden state dari langkah sebelumnya untuk membantu memproses input saat ini.

Secara sederhana, pembaruan hidden state dapat dituliskan sebagai:

\[ h_t=f(W_xx_t+W_hh_{t-1}+b) \]

Di sini, \(x_t\) adalah input pada waktu \(t\), \(h_{t-1}\) adalah hidden state sebelumnya, dan \(h_t\) adalah hidden state yang baru.

RNN dapat digunakan untuk memprediksi nilai berikutnya dalam deret waktu atau mengolah urutan token pada teks. Namun, RNN standar dapat mengalami masalah vanishing gradient ketika mempelajari ketergantungan jangka panjang. 

import torch
import torch.nn as nn

rnn = nn.RNN(
    input_size=5,
    hidden_size=16,
    num_layers=1,
    batch_first=True
)

X = torch.randn(8, 12, 5)

output, hidden = rnn(X)

print("Output:", output.shape)
print("Hidden state:", hidden.shape)

Bentuk input pada contoh adalah (batch_size, sequence_length, input_size). Dengan demikian, terdapat 8 urutan, masing-masing sepanjang 12 langkah, dan setiap langkah memiliki 5 fitur.

11. LSTM dan GRU

Long Short-Term Memory (LSTM) dan Gated Recurrent Unit (GRU) merupakan pengembangan RNN yang menggunakan mekanisme gerbang untuk mengatur informasi yang dipertahankan atau diperbarui.

LSTM

LSTM memiliki cell state dan beberapa gerbang, yaitu forget gate, input gate, dan output gate. Mekanisme ini membantu jaringan mempertahankan informasi penting dalam urutan yang panjang.

GRU

GRU menggunakan update gate dan reset gate. Arsitekturnya umumnya lebih sederhana dibandingkan LSTM karena tidak memiliki cell state terpisah.

Contoh LSTM dengan PyTorch:

import torch
import torch.nn as nn

lstm = nn.LSTM(
    input_size=5,
    hidden_size=32,
    num_layers=1,
    batch_first=True
)

X = torch.randn(8, 12, 5)

output, (hidden, cell) = lstm(X)

print("Output:", output.shape)
print("Hidden state:", hidden.shape)
print("Cell state:", cell.shape)

LSTM dan GRU dapat digunakan untuk prediksi deret waktu, pemrosesan teks, dan tugas lain yang memerlukan pemodelan urutan. Pemilihan antara keduanya bergantung pada karakteristik data, kebutuhan komputasi, dan hasil eksperimen.

12. Transformer dan Attention

Transformer adalah arsitektur yang menggunakan mekanisme attention untuk mempelajari hubungan antarelemen dalam sebuah urutan. Berbeda dengan RNN, Transformer dapat memproses banyak posisi secara paralel selama pelatihan, dengan memperhatikan batasan dan struktur input yang digunakan.

Scaled Dot-Product Attention

\[ \operatorname{Attention}(Q,K,V)= \operatorname{softmax} \left( \frac{QK^\top}{\sqrt{d_k}} \right)V \]

Keterangan:

  • Query (Q): mewakili informasi yang dicari.
  • Key (K): digunakan untuk menghitung kecocokan dengan query.
  • Value (V): informasi yang digabungkan berdasarkan bobot attention.
  • \(d_k\): dimensi vektor key yang digunakan untuk penskalaan.

Attention menghasilkan bobot yang menentukan seberapa besar setiap posisi memengaruhi representasi posisi lain. Multi-head attention menjalankan beberapa mekanisme attention agar model dapat mempelajari pola hubungan yang berbeda.

Transformer umumnya menggunakan:

  • Token embedding untuk merepresentasikan token.
  • Informasi posisi agar urutan token dapat diperhitungkan.
  • Multi-head attention untuk menggabungkan informasi ant posisi.
  • Feed-forward network untuk memproses representasi setiap posisi.
  • Residual connection dan normalisasi untuk membantu pelatihan.

Transformer banyak digunakan pada model bahasa, penerjemahan mesin, visi komputer, dan berbagai aplikasi multimodal.

13. Framework PyTorch atau TensorFlow

Framework deep learning menyediakan komponen untuk membangun jaringan, menghitung gradien secara otomatis, melatih model, dan menjalankan inferensi. Dua framework yang banyak digunakan adalah PyTorch dan TensorFlow.

PyTorch

PyTorch menyediakan tensor, automatic differentiation, modul jaringan saraf, optimizer, dan perangkat untuk memanfaatkan GPU. 

import torch
import torch.nn as nn

class NeuralNetwork(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()

        self.network = nn.Sequential(
            nn.Linear(input_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, output_size)
        )

    def forward(self, x):
        return self.network(x)

model = NeuralNetwork(
    input_size=4,
    hidden_size=16,
    output_size=1
)

X = torch.randn(32, 4)
prediksi = model(X)

print(prediksi.shape)

Contoh tersebut membangun jaringan dengan empat fitur input, satu hidden layer berisi 16 neuron, dan satu output. Kode ini baru menghasilkan prediksi; pelatihan memerlukan target, loss function, dan optimizer.

TensorFlow dan Keras

TensorFlow menyediakan ekosistem untuk membangun dan menjalankan model. Keras menyediakan antarmuka tingkat tinggi yang memudahkan penyusunan model melalui lapisan-lapisan. 

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Input(shape=(4,)),
    layers.Dense(16, activation="relu"),
    layers.Dense(1)
])

model.compile(
    optimizer="adam",
    loss="mse",
    metrics=["mae"]
)

model.summary()

Pada contoh ini, model disiapkan untuk regresi dengan empat fitur input dan satu output. Untuk melatihnya, gunakan model.fit(X_train, y_train, validation_data=(X_val, y_val), epochs=50) setelah menyiapkan data latih dan validasi dalam format yang sesuai.

Memilih framework

  • Pilih PyTorch jika ingin mempelajari alur tensor, gradien, dan loop pelatihan secara eksplisit.
  • Pilih TensorFlow/Keras jika menginginkan API tingkat tinggi untuk menyusun dan melatih model.
  • Keduanya mendukung banyak jenis arsitektur deep learning dan penggunaan akselerator yang kompatibel.

Ringkasan

  • Jaringan saraf tiruan terdiri dari neuron dan lapisan yang mempelajari pola dari data.
  • Activation function memungkinkan jaringan mempelajari hubungan nonlinier.
  • Forward propagation menghasilkan prediksi, sedangkan loss function mengukur kesalahan prediksi.
  • Backpropagation menghitung gradien dan optimizer menggunakannya untuk memperbarui parameter.
  • Gradient descent merupakan salah satu dasar optimasi jaringan saraf.
  • Regularisasi dan dropout membantu mengurangi risiko overfitting.
  • CNN banyak digunakan untuk data gambar, sedangkan RNN, LSTM, dan GRU dirancang untuk data berurutan.
  • Transformer memanfaatkan attention untuk memodelkan hubungan antarposisi dalam input.
  • PyTorch dan TensorFlow menyediakan perangkat untuk membangun, melatih, dan mengevaluasi model deep learning.
