Bagian VIII — Visualisasi Data

Visualisasi data adalah proses menyajikan informasi dalam bentuk grafik, diagram, peta, dan tampilan visual lainnya. Visualisasi membantu kita memahami pola, membandingkan nilai, menemukan anomali, serta mengomunikasikan hasil analisis secara lebih efektif. Dalam Data Science, visualisasi digunakan mulai dari eksplorasi data hingga penyajian hasil model dan pembangunan dashboard interaktif.

Pengantar Visualisasi Data

Data dalam bentuk tabel sering kali sulit dipahami ketika jumlah observasinya besar. Grafik dapat merangkum informasi sehingga pola tertentu lebih mudah terlihat.

Beberapa tujuan visualisasi data adalah:

  • Membandingkan nilai antar kategori.
  • Melihat perubahan variabel berdasarkan waktu.
  • Memahami distribusi dan penyebaran data.
  • Mengamati hubungan antara dua atau lebih variabel.
  • Mendeteksi anomali dan kemungkinan kesalahan data.
  • Menyampaikan hasil analisis kepada pengguna atau pengambil keputusan.

Pemilihan grafik harus mengikuti pertanyaan analisis. Grafik yang menarik belum tentu efektif apabila tidak menunjukkan informasi yang dibutuhkan.

Menyiapkan dataset

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.read_csv("penjualan.csv")

print(df.head())
print(df.info())
print(df.describe(include="all"))

Sebagai contoh, kita menggunakan dataset penjualan yang memiliki kolom tanggal, kategori, kota, jumlah produk, dan total penjualan. Sesuaikan nama kolom dengan dataset yang digunakan.

1. Matplotlib

Matplotlib adalah pustaka Python untuk membuat visualisasi statis, animasi, dan grafik interaktif dasar. Modul matplotlib.pyplot menyediakan fungsi yang umum digunakan untuk membuat dan mengatur grafik.

A. Grafik sederhana

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 15, 13, 20, 25]

plt.plot(x, y)
plt.title("Contoh Grafik Garis")
plt.xlabel("Waktu")
plt.ylabel("Nilai")
plt.show()

Fungsi yang sering digunakan:

  • plot(): membuat grafik garis.
  • scatter(): membuat scatter plot.
  • bar(): membuat diagram batang.
  • hist(): membuat histogram.
  • title(): memberikan judul grafik.
  • xlabel() dan ylabel(): memberi label sumbu.
  • legend(): menampilkan keterangan seri data.
  • grid(): menampilkan garis bantu.
  • savefig(): menyimpan grafik ke berkas.

B. Mengatur tampilan grafik

bulan = ["Jan", "Feb", "Mar", "Apr", "Mei"]
penjualan = [120, 150, 135, 180, 210]

plt.figure(figsize=(9, 5))
plt.plot(
    bulan,
    penjualan,
    marker="o",
    linewidth=2,
    label="Penjualan"
)

plt.title("Penjualan Bulanan")
plt.xlabel("Bulan")
plt.ylabel("Penjualan (juta rupiah)")
plt.legend()
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

Parameter figsize mengatur ukuran gambar, marker mengatur simbol pada titik data, dan linewidth mengatur ketebalan garis. tight_layout() membantu mencegah elemen grafik saling bertumpuk.

C. Menyimpan grafik

plt.figure(figsize=(8, 5))
plt.plot(bulan, penjualan, marker="o")
plt.title("Penjualan Bulanan")
plt.tight_layout()

plt.savefig(
    "penjualan_bulanan.png",
    dpi=300,
    bbox_inches="tight"
)

plt.show()

Gunakan resolusi yang sesuai dengan kebutuhan. Resolusi tinggi biasanya lebih bermanfaat untuk laporan atau dokumen cetak.

2. Seaborn

Seaborn merupakan pustaka visualisasi statistik berbasis Matplotlib. Seaborn menyediakan antarmuka yang praktis untuk membuat grafik distribusi, hubungan antarvariabel, kategori, dan matriks korelasi.

A. Membuat grafik berdasarkan DataFrame

import seaborn as sns
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "kategori": ["A", "B", "A", "B", "A", "B"],
    "penjualan": [120, 150, 135, 170, 145, 190]
})

sns.barplot(
    data=df,
    x="kategori",
    y="penjualan"
)

plt.title("Rata-rata Penjualan per Kategori")
plt.show()

Ketika menggunakan barplot() dengan data observasi mentah, Seaborn secara default menghitung estimasi statistik, biasanya rata-rata, dan menampilkan interval ketidakpastian. Grafik ini berbeda dari grafik batang yang menampilkan jumlah total yang telah dihitung sebelumnya.

B. Mengubah tema

sns.set_theme(style="whitegrid")

sns.histplot(
    data=df,
    x="penjualan",
    kde=True
)

plt.title("Distribusi Penjualan")
plt.show()

Tema seperti whitegrid, darkgrid, dan ticks membantu mengatur tampilan awal. Gunakan tema yang membuat data mudah dibaca dan tidak mengalihkan perhatian.

C. Memanfaatkan hue

sns.scatterplot(
    data=df,
    x="penjualan",
    y="penjualan",
    hue="kategori"
)

plt.show()

Parameter hue digunakan untuk membedakan kelompok melalui warna. Pada analisis nyata, pilih variabel sumbu yang berbeda dan relevan, misalnya jumlah produk pada sumbu horizontal dan total penjualan pada sumbu vertikal.

Seaborn cocok untuk eksplorasi data statistik, sedangkan Matplotlib memberi kendali lebih rinci terhadap elemen grafik. Keduanya dapat digunakan bersamaan.

3. Grafik Garis dan Batang

A. Grafik garis (line chart)

Grafik garis digunakan untuk menampilkan perubahan nilai sepanjang urutan tertentu, terutama waktu. Titik data dihubungkan oleh garis untuk membantu melihat tren, fluktuasi, dan perubahan. 

bulan = ["Jan", "Feb", "Mar", "Apr", "Mei", "Jun"]
penjualan = [100, 120, 115, 150, 170, 200]

plt.figure(figsize=(9, 5))
plt.plot(
    bulan,
    penjualan,
    marker="o",
    color="royalblue"
)

plt.title("Tren Penjualan")
plt.xlabel("Bulan")
plt.ylabel("Penjualan")
plt.tight_layout()
plt.show()

Grafik garis tepat digunakan ketika urutan titik memiliki makna, misalnya urutan waktu. Menghubungkan kategori yang tidak memiliki urutan alami dapat menimbulkan kesan kontinuitas yang tidak tepat.

B. Grafik garis dengan beberapa seri

bulan = ["Jan", "Feb", "Mar", "Apr"]
produk_a = [100, 120, 140, 160]
produk_b = [90, 110, 105, 150]

plt.figure(figsize=(9, 5))

plt.plot(bulan, produk_a, marker="o", label="Produk A")
plt.plot(bulan, produk_b, marker="s", label="Produk B")

plt.title("Perbandingan Penjualan Produk")
plt.xlabel("Bulan")
plt.ylabel("Penjualan")
plt.legend()
plt.tight_layout()
plt.show()

C. Diagram batang (bar chart)

Diagram batang digunakan untuk membandingkan nilai antar kategori. Panjang batang menunjukkan besarnya nilai. 

kategori = ["Laptop", "Ponsel", "Tablet", "Aksesori"]
jumlah = [80, 120, 65, 150]

plt.figure(figsize=(9, 5))
plt.bar(kategori, jumlah)

plt.title("Jumlah Produk Terjual")
plt.xlabel("Kategori")
plt.ylabel("Jumlah Terjual")
plt.tight_layout()
plt.show()

D. Diagram batang horizontal

kategori = ["Laptop", "Ponsel", "Tablet", "Aksesori"]
jumlah = [80, 120, 65, 150]

plt.figure(figsize=(8, 5))
plt.barh(kategori, jumlah)

plt.title("Jumlah Produk Terjual")
plt.xlabel("Jumlah Terjual")
plt.ylabel("Kategori")
plt.tight_layout()
plt.show()

Diagram horizontal bermanfaat jika nama kategori panjang. Untuk grafik batang biasa, sumbu nilai umumnya dimulai dari nol agar panjang batang tidak menyesatkan.

E. Grafik batang bertumpuk

kategori = ["Laptop", "Ponsel", "Tablet"]
online = [50, 80, 40]
offline = [30, 40, 25]

plt.figure(figsize=(8, 5))

plt.bar(kategori, online, label="Online")
plt.bar(
    kategori,
    offline,
    bottom=online,
    label="Offline"
)

plt.title("Penjualan Berdasarkan Kanal")
plt.xlabel("Kategori")
plt.ylabel("Jumlah")
plt.legend()
plt.tight_layout()
plt.show()

Grafik bertumpuk menunjukkan komposisi total. Jika tujuan utama adalah membandingkan setiap kelompok secara langsung, grafik batang berkelompok bisa lebih mudah dibaca.

4. Histogram dan Density Plot

Histogram dan density plot digunakan untuk memahami distribusi variabel numerik. Keduanya dapat menunjukkan konsentrasi data, kemencengan, dan kemungkinan beberapa puncak distribusi.

A. Histogram

Histogram membagi rentang nilai menjadi interval atau bin. Tinggi batang menunjukkan jumlah atau proporsi observasi dalam setiap interval, bergantung pada pengaturan histogram. 

np.random.seed(42)
nilai = np.random.normal(loc=70, scale=10, size=500)

plt.figure(figsize=(8, 5))
plt.hist(
    nilai,
    bins=20,
    edgecolor="black"
)

plt.title("Distribusi Nilai Ujian")
plt.xlabel("Nilai")
plt.ylabel("Frekuensi")
plt.tight_layout()
plt.show()

Pemilihan jumlah bin memengaruhi bentuk histogram. Terlalu sedikit bin dapat menyembunyikan pola, sedangkan terlalu banyak bin dapat membuat grafik tampak berisik.

B. Density plot

Density plot memperkirakan kepadatan probabilitas suatu distribusi. Berbeda dari histogram frekuensi, sumbu vertikalnya menyatakan kepadatan. Luas total di bawah kurva kepadatan adalah 1.

\[ \int_{-\infty}^{\infty} f(x)\,dx=1 \] 
plt.figure(figsize=(8, 5))

sns.kdeplot(
    data=df,
    x="penjualan",
    fill=True
)

plt.title("Kepadatan Distribusi Penjualan")
plt.xlabel("Penjualan")
plt.ylabel("Kepadatan")
plt.tight_layout()
plt.show()

KDE atau Kernel Density Estimation memperkirakan bentuk distribusi secara halus. Bentuk kurva dipengaruhi oleh bandwidth. Kurva yang terlalu halus dapat menyembunyikan pola, sedangkan kurva yang terlalu bergelombang dapat menonjolkan variasi acak.

C. Histogram dan density plot sekaligus

plt.figure(figsize=(8, 5))

sns.histplot(
    data=df,
    x="penjualan",
    bins=20,
    stat="density",
    kde=True
)

plt.title("Histogram dan Kurva Kepadatan")
plt.tight_layout()
plt.show()

Penggunaan stat="density" menyamakan skala histogram dengan kepadatan sehingga kurva KDE dapat dibandingkan secara lebih tepat.

5. Scatter Plot dan Bubble Chart

A. Scatter plot

Scatter plot menampilkan hubungan dua variabel numerik. Sumbu horizontal mewakili variabel \(x\), sedangkan sumbu vertikal mewakili variabel \(y\). Setiap titik mewakili satu observasi. 

np.random.seed(42)

luas = np.random.uniform(30, 200, 100)
harga = 100 + 5 * luas + np.random.normal(0, 100, 100)

plt.figure(figsize=(8, 5))
plt.scatter(luas, harga, alpha=0.7)

plt.title("Hubungan Luas dan Harga Rumah")
plt.xlabel("Luas Rumah (m²)")
plt.ylabel("Harga (juta rupiah)")
plt.tight_layout()
plt.show()

Scatter plot dapat digunakan untuk mengidentifikasi:

  • Hubungan positif atau negatif.
  • Hubungan linear atau nonlinier.
  • Kelompok observasi.
  • Variasi data dan kandidat outlier.

B. Menambahkan garis tren

sns.regplot(
    data=df,
    x="luas",
    y="harga",
    scatter_kws={"alpha": 0.6},
    line_kws={"color": "red"}
)

plt.title("Luas dan Harga Rumah dengan Garis Tren")
plt.tight_layout()
plt.show()

Garis regresi linear merangkum tren linear dalam data. Garis tersebut tidak otomatis membuktikan hubungan sebab-akibat dan dapat kurang sesuai jika pola sebenarnya nonlinier.

C. Bubble chart

Bubble chart merupakan scatter plot yang menggunakan ukuran titik untuk mewakili variabel ketiga. Warna dapat digunakan untuk menunjukkan kelompok atau variabel tambahan. 

data_bubble = pd.DataFrame({
    "iklan": [10, 20, 30, 40, 50],
    "penjualan": [100, 150, 180, 240, 300],
    "pelanggan": [20, 35, 30, 50, 70]
})

plt.figure(figsize=(8, 5))

plt.scatter(
    data_bubble["iklan"],
    data_bubble["penjualan"],
    s=data_bubble["pelanggan"] * 10,
    alpha=0.6
)

plt.title("Biaya Iklan, Penjualan, dan Pelanggan")
plt.xlabel("Biaya Iklan")
plt.ylabel("Penjualan")
plt.tight_layout()
plt.show()

Pada contoh tersebut, posisi titik menunjukkan biaya iklan dan penjualan, sedangkan ukuran lingkaran menunjukkan jumlah pelanggan. Ukuran yang digunakan pada parameter s menyatakan luas marker dalam satuan visualisasi Matplotlib.

Bubble chart sebaiknya tidak menggunakan terlalu banyak variabel visual sekaligus. Perbedaan luas lingkaran juga lebih sulit dipersepsikan daripada perbedaan posisi sehingga skala ukuran perlu dipilih dengan hati-hati.

6. Boxplot dan Violin Plot

A. Boxplot

Boxplot merangkum distribusi data menggunakan kuartil, median, dan whisker. Pada pengaturan umum Seaborn, whisker mencapai nilai terjauh yang masih berada dalam rentang \(1.5 \times IQR\) dari kuartil pertama dan ketiga. Titik di luar whisker ditampilkan sebagai kandidat outlier.

\[ IQR=Q_3-Q_1 \] 
plt.figure(figsize=(8, 5))

sns.boxplot(
    data=df,
    x="kategori",
    y="penjualan"
)

plt.title("Distribusi Penjualan per Kategori")
plt.tight_layout()
plt.show()

Boxplot membantu membandingkan:

  • Median setiap kelompok.
  • Rentang antarkuartil.
  • Penyebaran dan kemencengan distribusi.
  • Observasi yang jauh dari sebagian besar data.

B. Violin plot

Violin plot menggabungkan informasi kepadatan distribusi dengan ringkasan seperti median dan kuartil. Lebar bentuk pada suatu nilai menunjukkan perkiraan kepadatan data di sekitar nilai tersebut. 

plt.figure(figsize=(8, 5))

sns.violinplot(
    data=df,
    x="kategori",
    y="penjualan",
    inner="quartile",
    cut=0
)

plt.title("Distribusi Penjualan per Kategori")
plt.tight_layout()
plt.show()

C. Memilih boxplot atau violin plot

Aspek Boxplot Violin plot
Fokus Median, kuartil, dan penyebaran Bentuk dan kepadatan distribusi
Kelebihan Ringkas dan mudah dibandingkan Memperlihatkan kemungkinan beberapa puncak
Keterbatasan Tidak menunjukkan bentuk distribusi secara rinci Bentuk kepadatan bergantung pada estimasi KDE

Jika jumlah data kecil, violin plot dapat memberikan kesan bentuk distribusi yang lebih pasti daripada yang didukung oleh data. Gunakan grafik dengan memperhatikan ukuran sampel.

7. Heatmap dan Correlation Matrix

A. Correlation matrix

Matriks korelasi merangkum korelasi antara setiap pasangan variabel numerik. Untuk korelasi Pearson, nilai berada pada rentang \(-1\) sampai \(1\).

\[ -1 \leq r_{ij} \leq 1 \]

Nilai positif menunjukkan hubungan linear positif, nilai negatif menunjukkan hubungan linear negatif, dan nilai mendekati nol menunjukkan hubungan linear yang lemah. 

fitur_numerik = df.select_dtypes(include="number")

corr = fitur_numerik.corr(method="pearson")

print(corr)

B. Heatmap korelasi

plt.figure(figsize=(10, 7))

sns.heatmap(
    corr,
    annot=True,
    cmap="coolwarm",
    fmt=".2f",
    vmin=-1,
    vmax=1,
    center=0
)

plt.title("Correlation Matrix")
plt.tight_layout()
plt.show()

Heatmap menggunakan warna untuk memperlihatkan besar dan arah korelasi. Penggunaan skala warna yang konsisten, misalnya dari \(-1\) sampai \(1\), memudahkan perbandingan antar pasangan variabel.

C. Korelasi tidak sama dengan sebab-akibat

Jika dua variabel memiliki korelasi tinggi, kita tidak dapat langsung menyimpulkan bahwa salah satunya menyebabkan perubahan pada variabel lain. Hubungan tersebut dapat dipengaruhi variabel ketiga, struktur data, atau cara pengambilan sampel.

Korelasi Pearson juga terutama mengukur hubungan linear. Untuk hubungan monotonik yang tidak harus linear, korelasi Spearman dapat menjadi alternatif. 

corr_spearman = fitur_numerik.corr(method="spearman")

plt.figure(figsize=(10, 7))
sns.heatmap(
    corr_spearman,
    annot=True,
    cmap="coolwarm",
    fmt=".2f",
    vmin=-1,
    vmax=1,
    center=0
)

plt.title("Correlation Matrix Spearman")
plt.tight_layout()
plt.show()

8. Visualisasi Multivariabel

Visualisasi multivariabel menyajikan informasi dari tiga variabel atau lebih secara bersamaan. Selain posisi pada sumbu \(x\) dan \(y\), variabel tambahan dapat diwakili melalui warna, ukuran, bentuk, panel, atau facet.

A. Scatter plot dengan warna dan bentuk

sns.scatterplot(
    data=df,
    x="jumlah_produk",
    y="total_penjualan",
    hue="kategori",
    style="kota",
    size="diskon",
    sizes=(30, 200),
    alpha=0.7
)

plt.title("Analisis Penjualan Multivariabel")
plt.tight_layout()
plt.show()

Grafik ini menunjukkan jumlah produk, total penjualan, kategori, kota, dan diskon dalam satu tampilan. Namun, semakin banyak variabel visual yang digunakan, semakin besar risiko grafik sulit dipahami.

B. Pair plot

Pair plot menampilkan scatter plot untuk pasangan fitur numerik serta distribusi setiap fitur pada diagonal. 

fitur = [
    "usia",
    "pendapatan",
    "jumlah_transaksi",
    "total_pengeluaran"
]

sns.pairplot(
    df[fitur].dropna(),
    diag_kind="hist"
)

plt.show()

Pair plot cocok untuk eksplorasi beberapa fitur numerik. Untuk dataset dengan banyak fitur, pilih fitur yang relevan agar hasilnya tidak terlalu padat.

C. Facet grid

Facet grid membagi data menjadi beberapa panel berdasarkan kategori. Metode ini berguna untuk membandingkan pola pada kelompok berbeda dengan sumbu yang serupa. 

g = sns.relplot(
    data=df,
    x="jumlah_produk",
    y="total_penjualan",
    col="kota",
    hue="kategori",
    kind="scatter",
    height=4,
    aspect=1
)

g.set_axis_labels("Jumlah Produk", "Total Penjualan")
g.set_titles("Kota: {col_name}")

plt.show()

D. Memilih teknik multivariabel

  • Gunakan warna untuk membedakan kelompok atau kategori.
  • Gunakan ukuran untuk variabel numerik tambahan yang penting.
  • Gunakan panel terpisah jika kelompok sulit dibandingkan dalam satu grafik.
  • Gunakan heatmap untuk matriks hubungan atau data berbentuk tabel.
  • Gunakan pair plot untuk eksplorasi awal beberapa fitur numerik.

9. Prinsip Desain Visualisasi

Visualisasi yang baik tidak hanya benar secara teknis, tetapi juga mudah dibaca, akurat, dan sesuai dengan kebutuhan audiens.

A. Pilih grafik berdasarkan tujuan

Tujuan Grafik yang dapat digunakan
Membandingkan kategori Diagram batang
Melihat tren waktu Grafik garis
Memahami distribusi Histogram atau density plot
Melihat hubungan dua variabel numerik Scatter plot
Membandingkan distribusi antar kelompok Boxplot atau violin plot
Melihat korelasi banyak variabel Heatmap
Menyajikan indikator dan ringkasan interaktif Dashboard

B. Beri judul dan label yang jelas

Judul sebaiknya menjelaskan isi atau pesan utama grafik. Label sumbu harus mencantumkan nama variabel dan satuannya jika tersedia. Hindari judul yang terlalu umum seperti "Grafik 1" atau "Hasil Analisis".

C. Gunakan warna secara konsisten

  • Gunakan warna yang mudah dibedakan.
  • Pastikan kontras antara data dan latar belakang memadai.
  • Pertimbangkan pengguna dengan gangguan persepsi warna.
  • Gunakan warna yang sama untuk kategori yang sama pada beberapa grafik.
  • Jangan mengandalkan warna saja untuk menyampaikan informasi penting.

D. Hindari distorsi visual

  • Hindari efek tiga dimensi yang tidak menambah informasi.
  • Jangan memotong sumbu secara menyesatkan.
  • Jangan menggunakan ukuran simbol yang tidak sesuai dengan data.
  • Jangan menampilkan terlalu banyak kategori dalam satu grafik.
  • Jangan menggabungkan terlalu banyak skala yang sulit dibandingkan.

E. Perhatikan konteks statistik

Visualisasi perlu mempertimbangkan ukuran sampel, ketidakpastian, data kosong, dan metode agregasi. Rata-rata dapat menyembunyikan perbedaan antarindividu, sedangkan jumlah total dapat dipengaruhi oleh perbedaan ukuran kelompok.

F. Contoh grafik dengan desain yang rapi

sns.set_theme(style="whitegrid")

fig, ax = plt.subplots(figsize=(9, 5))

sns.barplot(
    data=df,
    x="kategori",
    y="total_penjualan",
    errorbar=None,
    ax=ax
)

ax.set_title(
    "Rata-rata Penjualan Berdasarkan Kategori",
    fontsize=14
)
ax.set_xlabel("Kategori Produk")
ax.set_ylabel("Rata-rata Penjualan")
ax.tick_params(axis="x", rotation=25)

fig.tight_layout()
plt.show()

Pada contoh ini, errorbar=None menyembunyikan interval ketidakpastian. Gunakan opsi tersebut hanya jika memang ingin menampilkan ringkasan tanpa interval; untuk analisis statistik, interval ketidakpastian dapat menjadi informasi penting.

10. Dashboard Interaktif dengan Plotly atau Streamlit

Dashboard adalah tampilan yang menggabungkan beberapa visualisasi dan indikator untuk membantu pengguna memahami data. Dashboard interaktif memungkinkan pengguna memilih rentang waktu, kategori, wilayah, atau filter lain untuk mengeksplorasi informasi.

A. Plotly Express

Plotly Express menyediakan cara ringkas untuk membuat grafik interaktif. Grafik yang dihasilkan umumnya mendukung hover, zoom, dan interaksi lainnya. 

import pandas as pd
import plotly.express as px

df = pd.read_csv("penjualan.csv")

fig = px.line(
    df,
    x="tanggal",
    y="total_penjualan",
    color="kategori",
    title="Tren Penjualan Berdasarkan Kategori",
    markers=True
)

fig.update_layout(
    xaxis_title="Tanggal",
    yaxis_title="Total Penjualan",
    template="plotly_white"
)

fig.show()

B. Scatter plot interaktif

fig = px.scatter(
    df,
    x="jumlah_produk",
    y="total_penjualan",
    color="kategori",
    size="diskon",
    hover_data=["kota"],
    title="Analisis Penjualan Interaktif"
)

fig.show()

Kolom yang dipakai pada parameter size sebaiknya berisi nilai numerik yang sesuai. Periksa nilai kosong, nilai negatif, dan skala variabel sebelum membuat bubble chart.

C. Membuat dashboard dengan Streamlit

Streamlit adalah framework Python untuk membangun aplikasi data interaktif. Kita dapat menggabungkan filter, metrik, tabel, dan grafik tanpa harus membangun antarmuka web dari awal.

Instal pustaka yang diperlukan melalui terminal: 

pip install streamlit pandas plotly

D. Contoh aplikasi dashboard

Buat file bernama app.py dengan kode berikut. Dataset penjualan.csv diasumsikan memiliki kolom tanggal, kategori, kota, dan total_penjualan. 

import streamlit as st
import pandas as pd
import plotly.express as px

st.set_page_config(
    page_title="Dashboard Penjualan",
    page_icon="📊",
    layout="wide"
)

st.title("Dashboard Analisis Penjualan")
st.write(
    "Eksplorasi penjualan berdasarkan kategori, "
    "wilayah, dan waktu."
)

@st.cache_data
def load_data():
    data = pd.read_csv("penjualan.csv")
    data["tanggal"] = pd.to_datetime(
        data["tanggal"],
        errors="coerce"
    )
    data["total_penjualan"] = pd.to_numeric(
        data["total_penjualan"],
        errors="coerce"
    )
    return data

df = load_data()

df = df.dropna(
    subset=["tanggal", "total_penjualan"]
).copy()

if df.empty:
    st.warning("Dataset tidak memiliki baris valid.")
    st.stop()

kategori_opsi = sorted(
    df["kategori"].dropna().unique().tolist()
)
kota_opsi = sorted(
    df["kota"].dropna().unique().tolist()
)

st.sidebar.header("Filter Data")

kategori_pilih = st.sidebar.multiselect(
    "Pilih kategori",
    options=kategori_opsi,
    default=kategori_opsi
)

kota_pilih = st.sidebar.multiselect(
    "Pilih kota",
    options=kota_opsi,
    default=kota_opsi
)

data_filter = df[
    df["kategori"].isin(kategori_pilih)
    & df["kota"].isin(kota_pilih)
].copy()

if data_filter.empty:
    st.info("Tidak ada data untuk filter yang dipilih.")
    st.stop()

total_penjualan = data_filter["total_penjualan"].sum()
rata_rata = data_filter["total_penjualan"].mean()
jumlah_transaksi = len(data_filter)

kolom1, kolom2, kolom3 = st.columns(3)

kolom1.metric(
    "Total Penjualan",
    f"{total_penjualan:,.0f}"
)

kolom2.metric(
    "Rata-rata Transaksi",
    f"{rata_rata:,.0f}"
)

kolom3.metric(
    "Jumlah Observasi",
    f"{jumlah_transaksi:,}"
)

data_waktu = (
    data_filter
    .groupby(
        [
            pd.Grouper(key="tanggal", freq="ME"),
            "kategori"
        ],
        as_index=False
    )["total_penjualan"]
    .sum()
)

fig_garis = px.line(
    data_waktu,
    x="tanggal",
    y="total_penjualan",
    color="kategori",
    markers=True,
    title="Tren Penjualan Bulanan"
)

st.plotly_chart(
    fig_garis,
    use_container_width=True
)

data_kategori = (
    data_filter
    .groupby("kategori", as_index=False)
    ["total_penjualan"]
    .sum()
    .sort_values("total_penjualan", ascending=False)
)

fig_batang = px.bar(
    data_kategori,
    x="kategori",
    y="total_penjualan",
    title="Total Penjualan per Kategori"
)

st.plotly_chart(
    fig_batang,
    use_container_width=True
)

st.subheader("Data yang Telah Difilter")
st.dataframe(data_filter, use_container_width=True)

csv = data_filter.to_csv(index=False).encode("utf-8")

st.download_button(
    label="Unduh Data Hasil Filter",
    data=csv,
    file_name="penjualan_terfilter.csv",
    mime="text/csv"
)

Proyek Mini: Dashboard Penjualan Interaktif

Bangun dashboard untuk menganalisis penjualan berdasarkan waktu, kategori produk, dan wilayah.

Tujuan proyek

  • Menampilkan total penjualan dan jumlah observasi.
  • Membandingkan total penjualan antar kategori.
  • Menampilkan tren penjualan berdasarkan waktu.
  • Memungkinkan pengguna memilih kota dan kategori.
  • Menyediakan tabel data hasil filter.

Alur pengerjaan

  1. Siapkan dataset dan periksa nama serta tipe kolom.
  2. Bersihkan nilai tanggal dan penjualan yang tidak valid.
  3. Buat ringkasan statistik menggunakan Pandas.
  4. Buat grafik garis dan batang menggunakan Plotly.
  5. Tambahkan filter interaktif dengan Streamlit.
  6. Tambahkan indikator utama dan tabel hasil filter.
  7. Uji dashboard dengan berbagai kombinasi filter.
  8. Periksa apakah angka pada metrik konsisten dengan tabel dan grafik.

Dashboard yang baik harus memberikan hasil yang konsisten. Jika pengguna mengubah filter, semua metrik dan grafik yang terkait perlu mengikuti pilihan tersebut.

Latihan Mandiri

  1. Jelaskan perbedaan Matplotlib dan Seaborn serta kondisi yang cocok untuk menggunakan masing-masing pustaka.
  2. Jenis grafik apa yang paling sesuai untuk menampilkan perubahan penjualan bulanan? Jelaskan alasannya.
  3. Buat diagram batang yang membandingkan jumlah produk terjual pada lima kategori.
  4. Apa perbedaan histogram dan density plot?
  5. Buat scatter plot untuk mengamati hubungan antara biaya iklan dan penjualan.
  6. Jelaskan bagaimana bubble chart menampilkan variabel ketiga dan apa kelemahannya.
  7. Apa perbedaan informasi yang disajikan boxplot dan violin plot?
  8. Buat heatmap korelasi untuk semua fitur numerik pada dataset yang dipilih.
  9. Sebutkan tiga prinsip desain yang dapat mencegah visualisasi menjadi menyesatkan.
  10. Buat dashboard Streamlit dengan minimal dua filter, tiga metrik, dua grafik, dan satu tabel.

Ringkasan

  • Visualisasi data membantu memahami pola dan mengomunikasikan hasil analisis.
  • Matplotlib menyediakan kontrol yang fleksibel terhadap elemen grafik, sedangkan Seaborn memudahkan visualisasi statistik.
  • Grafik garis sesuai untuk tren berurutan, sedangkan diagram batang sesuai untuk perbandingan kategori.
  • Histogram dan density plot digunakan untuk memahami distribusi data numerik.
  • Scatter plot dan bubble chart menampilkan hubungan antarvariabel numerik.
  • Boxplot dan violin plot membantu membandingkan distribusi antar kelompok.
  • Heatmap dapat menyajikan matriks korelasi secara ringkas, tetapi korelasi tidak membuktikan sebab-akibat.
  • Visualisasi multivariabel menggunakan posisi, warna, ukuran, bentuk, atau panel untuk menyajikan informasi tambahan.
  • Desain visualisasi harus jelas, akurat, konsisten, dan tidak menyesatkan.
  • Plotly menyediakan grafik interaktif, sedangkan Streamlit membantu membangun dashboard berbasis Python.
