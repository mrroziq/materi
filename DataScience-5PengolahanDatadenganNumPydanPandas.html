DATA SCIENCE DAN PENGOLAHAN DATA

Bagian V — Pengolahan Data dengan NumPy dan Pandas

Pengolahan data merupakan tahapan penting dalam data science. Data mentah sering kali memiliki struktur yang belum sesuai untuk analisis sehingga perlu dibaca, dipilih, dibersihkan, digabungkan, dan ditransformasikan. NumPy menyediakan struktur array dan operasi numerik yang efisien, sedangkan Pandas menyediakan Series dan DataFrame untuk mengolah data tabular secara sistematis.

1. Array dan Operasi Vektor Menggunakan NumPy

NumPy (Numerical Python) adalah pustaka Python untuk komputasi numerik. Struktur utamanya adalah ndarray, yaitu array multidimensi yang memungkinkan operasi matematika dilakukan secara efisien pada banyak elemen sekaligus.

a. Membuat array

import numpy as np

# Array satu dimensi
nilai = np.array([70, 80, 90, 85])

# Array dua dimensi
matriks = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(nilai)
print(matriks)
print("Dimensi:", matriks.ndim)
print("Bentuk:", matriks.shape)
print("Jumlah elemen:", matriks.size)

Array di atas memiliki bentuk \(2\times3\), yaitu dua baris dan tiga kolom.

b. Membuat array dengan fungsi khusus

import numpy as np

print(np.zeros((2, 3)))
print(np.ones((2, 2)))
print(np.arange(0, 10, 2))
print(np.linspace(0, 1, 5))

Fungsi zeros() menghasilkan array berisi nol, ones() menghasilkan array berisi satu, arange() menghasilkan urutan dengan interval tertentu, dan linspace() menghasilkan sejumlah nilai dengan jarak yang sama pada suatu interval.

c. Operasi vektor

Operasi vektor dapat dilakukan langsung terhadap array tanpa harus menuliskan perulangan secara eksplisit. Operasi ini biasanya diterapkan elemen demi elemen.

\[ \mathbf{a}=(a_1,\ldots,a_n),\qquad \mathbf{b}=(b_1,\ldots,b_n) \]

Penjumlahan dua vektor didefinisikan sebagai

\[ \mathbf{a}+\mathbf{b} =(a_1+b_1,\ldots,a_n+b_n) \] 
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a + b)
print(a * b)
print(a ** 2)
print(np.dot(a, b))
print(np.mean(a))
print(np.sum(a))

Hasilnya berturut-turut:

[5 7 9]
[ 4 10 18]
[1 4 9]
32
2.0
6

Perlu dibedakan antara perkalian elemen demi elemen, yang ditulis a * b, dan perkalian titik atau dot product, yang menghitung \(\mathbf{a}\cdot\mathbf{b}=\sum_i a_i b_i\).

d. Broadcasting

Broadcasting memungkinkan operasi antara array dan nilai atau array lain yang bentuknya kompatibel. 

import numpy as np

nilai = np.array([60, 70, 80, 90])

# Menambahkan 5 pada setiap elemen
print(nilai + 5)

# Mengubah skala nilai
print(nilai / 100)

Broadcasting mengurangi kebutuhan perulangan manual. Namun, operasi antara dua array tetap harus memenuhi aturan kompatibilitas bentuk NumPy.

2. Series dan DataFrame

Pandas adalah pustaka untuk mengolah data tabular. Dua struktur utamanya adalah Series dan DataFrame.

a. Series

Series merupakan struktur data satu dimensi yang memiliki label indeks. Series dapat digunakan untuk merepresentasikan satu kolom data. 

import pandas as pd

nilai = pd.Series(
    [80, 90, 75, 85],
    index=["Ani", "Budi", "Citra", "Doni"],
    name="Nilai"
)

print(nilai)
print("Nilai Ani:", nilai["Ani"])
print("Rata-rata:", nilai.mean())

b. DataFrame

DataFrame merupakan struktur data dua dimensi berbentuk tabel yang memiliki label baris dan kolom. Setiap kolom dapat memiliki tipe data yang berbeda. 

import pandas as pd

data = {
    "Nama": ["Ani", "Budi", "Citra", "Doni"],
    "Usia": [20, 21, 19, 22],
    "Nilai": [80, 90, 75, 85]
}

df = pd.DataFrame(data)

print(df)
print(df.shape)
print(df.columns)
print(df.dtypes)
print(df.info())

Atribut shape memberikan jumlah baris dan kolom. Atribut columns menunjukkan nama kolom, sedangkan dtypes menunjukkan tipe data setiap kolom.

c. Ringkasan data

print(df.head())
print(df.tail())
print(df.describe())
print(df["Nama"].value_counts())

head() menampilkan baris awal, tail() menampilkan baris akhir, describe() merangkum statistik numerik, dan value_counts() menghitung frekuensi setiap nilai.

3. Membaca CSV, Excel, dan JSON

Data untuk analisis dapat berasal dari berbagai format berkas. Pandas menyediakan fungsi untuk membaca berbagai format tersebut ke dalam DataFrame.

a. Membaca CSV

import pandas as pd

df = pd.read_csv("data_mahasiswa.csv")

print(df.head())

CSV merupakan format teks yang menyimpan data berbentuk tabel. Jika pemisah kolom berupa titik koma, gunakan parameter sep=";". 

df = pd.read_csv(
    "data_mahasiswa.csv",
    sep=";",
    encoding="utf-8"
)

b. Membaca Excel

import pandas as pd

df = pd.read_excel("data_mahasiswa.xlsx")

# Membaca sheet tertentu
df = pd.read_excel(
    "data_mahasiswa.xlsx",
    sheet_name="Mahasiswa"
)

Pembacaan berkas Excel biasanya membutuhkan mesin pembaca seperti openpyxl untuk format .xlsx. Jika diperlukan, instal pustaka tersebut melalui pip. 

pip install openpyxl

c. Membaca JSON

import pandas as pd

df = pd.read_json("data_mahasiswa.json")

print(df.head())

JSON sering digunakan untuk pertukaran data antara aplikasi dan API. Struktur JSON dapat berupa daftar objek, objek bersarang, atau bentuk lainnya. Untuk JSON bertingkat, fungsi json_normalize() dapat membantu meratakan struktur tertentu. 

import json
import pandas as pd

with open("data_mahasiswa.json", encoding="utf-8") as file:
    data = json.load(file)

df = pd.json_normalize(data)
print(df.head())

Periksa selalu nama kolom, jumlah baris, tipe data, dan nilai yang hilang setelah membaca berkas. Untuk dataset besar, gunakan parameter seperti usecols atau chunksize pada pembacaan CSV jika sesuai kebutuhan.

4. Memilih Baris dan Kolom

Pemilihan baris dan kolom memungkinkan kita mengambil bagian data yang diperlukan tanpa mengolah seluruh tabel.

a. Memilih kolom

# Memilih satu kolom
nama = df["Nama"]

# Memilih beberapa kolom
subset = df[["Nama", "Nilai"]]

print(subset)

b. Menggunakan loc

loc memilih data berdasarkan label indeks dan nama kolom. 

# Memilih baris dengan label indeks 0
print(df.loc[0])

# Memilih baris dan kolom tertentu
print(df.loc[0:2, ["Nama", "Nilai"]])

Pada pemilihan berbasis label, rentang loc[0:2] umumnya mencakup label awal dan akhir, yaitu 0, 1, dan 2.

c. Menggunakan iloc

iloc memilih data berdasarkan posisi bilangan bulat, dimulai dari indeks posisi 0. 

# Baris pertama
print(df.iloc[0])

# Dua baris pertama dan dua kolom pertama
print(df.iloc[0:2, 0:2])

Berbeda dari loc, batas akhir pada pemotongan posisi menggunakan iloc tidak disertakan.

d. Mengubah nilai

df.loc[0, "Nilai"] = 95
df.loc[df["Nama"] == "Budi", "Nilai"] = 92

print(df)

Gunakan loc untuk penetapan nilai secara eksplisit. Cara ini membantu menghindari masalah perubahan data melalui salinan atau tampilan sementara.

5. Filtering dan Sorting

Filtering digunakan untuk memilih baris berdasarkan kondisi tertentu. Sorting digunakan untuk mengurutkan data menurut nilai satu atau beberapa kolom.

a. Filtering

# Memilih mahasiswa dengan nilai minimal 80
lulus = df[df["Nilai"] >= 80]

# Dua kondisi sekaligus
hasil = df[
    (df["Nilai"] >= 80) &
    (df["Usia"] >= 20)
]

# Salah satu dari dua kondisi
hasil_lain = df[
    (df["Nilai"] >= 90) |
    (df["Usia"] < 20)
]

print(lulus)
print(hasil)

Gunakan operator & untuk kondisi AND dan | untuk kondisi OR. Setiap kondisi perlu diberi tanda kurung.

b. Menggunakan isin dan query

# Memilih nama tertentu
pilihan = df[df["Nama"].isin(["Ani", "Citra"])]

# Menyaring dengan ekspresi query
nilai_tinggi = df.query("Nilai >= 85")

print(pilihan)
print(nilai_tinggi)

c. Sorting

# Mengurutkan nilai dari kecil ke besar
urut_naik = df.sort_values("Nilai")

# Mengurutkan nilai dari besar ke kecil
urut_turun = df.sort_values(
    "Nilai",
    ascending=False
)

# Mengurutkan berdasarkan dua kolom
urut_ganda = df.sort_values(
    ["Usia", "Nilai"],
    ascending=[True, False]
)

print(urut_turun)

Filtering dan sorting sering digunakan untuk mengeksplorasi data, mencari observasi tertentu, dan menyiapkan subset untuk analisis lanjutan.

6. Grouping dan Agregasi

Grouping membagi data ke dalam kelompok berdasarkan nilai kategori tertentu. Agregasi menghitung ringkasan pada setiap kelompok, misalnya mean, jumlah, minimum, maksimum, atau banyaknya observasi.

a. GroupBy

import pandas as pd

data = {
    "Jurusan": ["Matematika", "Statistika", "Matematika",
                "Statistika", "Matematika"],
    "Nilai": [80, 85, 90, 75, 95]
}

df = pd.DataFrame(data)

rata_rata = df.groupby("Jurusan")["Nilai"].mean()

print(rata_rata)

Data dikelompokkan menurut jurusan, kemudian mean nilai dihitung untuk setiap kelompok.

b. Beberapa agregasi sekaligus

ringkasan = df.groupby("Jurusan").agg(
    jumlah=("Nilai", "count"),
    rata_rata=("Nilai", "mean"),
    minimum=("Nilai", "min"),
    maksimum=("Nilai", "max")
)

print(ringkasan)

c. Grouping dengan lebih dari satu kolom

data = {
    "Jurusan": ["Matematika", "Matematika",
                "Statistika", "Statistika"],
    "Angkatan": [2024, 2025, 2024, 2025],
    "Nilai": [80, 90, 85, 88]
}

df = pd.DataFrame(data)

hasil = df.groupby(
    ["Jurusan", "Angkatan"]
)["Nilai"].mean()

print(hasil)

Grouping digunakan dalam analisis penjualan per wilayah, rata-rata nilai per jurusan, jumlah transaksi per bulan, dan berbagai ringkasan data lain.

7. Merge, Join, dan Concatenation

Dataset sering disimpan dalam beberapa tabel. Pandas menyediakan operasi untuk menggabungkan tabel berdasarkan kunci maupun menyatukan data berdasarkan baris atau kolom.

a. Merge

merge() menggabungkan dua DataFrame berdasarkan satu atau beberapa kolom kunci. 

import pandas as pd

mahasiswa = pd.DataFrame({
    "ID": [1, 2, 3],
    "Nama": ["Ani", "Budi", "Citra"]
})

nilai = pd.DataFrame({
    "ID": [1, 2, 3],
    "Nilai": [85, 90, 78]
})

gabungan = pd.merge(
    mahasiswa,
    nilai,
    on="ID",
    how="inner"
)

print(gabungan)

Jenis merge yang umum:

  • inner: hanya kunci yang cocok di kedua tabel.
  • left: seluruh baris dari tabel kiri, ditambah pasangan yang cocok.
  • right: seluruh baris dari tabel kanan, ditambah pasangan yang cocok.
  • outer: seluruh kunci dari kedua tabel.

b. Join

join() lazim digunakan untuk menggabungkan DataFrame berdasarkan indeks. 

profil = pd.DataFrame(
    {"Jurusan": ["Matematika", "Statistika"]},
    index=[1, 2]
)

nilai = pd.DataFrame(
    {"Nilai": [85, 90]},
    index=[1, 2]
)

hasil = profil.join(nilai)
print(hasil)

c. Concatenation

concat() menyatukan beberapa DataFrame sepanjang baris atau kolom. 

data_a = pd.DataFrame({
    "Nama": ["Ani", "Budi"],
    "Nilai": [80, 85]
})

data_b = pd.DataFrame({
    "Nama": ["Citra", "Doni"],
    "Nilai": [90, 88]
})

# Menyatukan baris
gabungan_baris = pd.concat(
    [data_a, data_b],
    ignore_index=True
)

print(gabungan_baris)

Periksa keunikan kunci sebelum melakukan merge. Jika satu kunci muncul berulang kali pada kedua tabel, hasil penggabungan dapat menghasilkan banyak baris akibat pencocokan banyak-ke-banyak.

8. Manipulasi Tanggal dan Waktu

Data tanggal dan waktu sering muncul dalam transaksi, log aplikasi, data sensor, dan riwayat aktivitas. Pandas menyediakan tipe datetime serta fungsi untuk mengubah format, mengekstrak komponen waktu, dan melakukan perhitungan tanggal.

a. Mengubah kolom menjadi datetime

import pandas as pd

df = pd.DataFrame({
    "Tanggal": [
        "2026-01-05",
        "2026-02-12",
        "2026-03-20"
    ],
    "Penjualan": [100, 150, 200]
})

df["Tanggal"] = pd.to_datetime(df["Tanggal"])

print(df.dtypes)

b. Mengekstrak komponen tanggal

df["Tahun"] = df["Tanggal"].dt.year
df["Bulan"] = df["Tanggal"].dt.month
df["Hari"] = df["Tanggal"].dt.day
df["NamaHari"] = df["Tanggal"].dt.day_name()

print(df)

c. Menghitung selisih waktu

df["Tanggal"] = pd.to_datetime(df["Tanggal"])

tanggal_awal = pd.Timestamp("2026-01-01")

df["SelisihHari"] = (
    df["Tanggal"] - tanggal_awal
).dt.days

print(df[["Tanggal", "SelisihHari"]])

d. Mengelompokkan berdasarkan periode

penjualan_bulanan = (
    df.set_index("Tanggal")["Penjualan"]
      .resample("MS")
      .sum()
)

print(penjualan_bulanan)

Kode tersebut menjumlahkan penjualan per bulan, dengan periode dimulai pada awal setiap bulan. Frekuensi seperti harian, mingguan, dan bulanan dapat digunakan sesuai kebutuhan analisis.

Jika data memiliki zona waktu, perhatikan perbedaan waktu lokal dan UTC. Gunakan konversi zona waktu yang sesuai sebelum membandingkan waktu dari sumber berbeda.

9. Missing Values dan Duplikasi

Missing values adalah nilai yang tidak tersedia, sedangkan duplikasi terjadi ketika terdapat baris atau observasi yang berulang. Keduanya perlu diperiksa sebelum analisis karena dapat memengaruhi hasil.

a. Memeriksa nilai yang hilang

import pandas as pd
import numpy as np

df = pd.DataFrame({
    "Nama": ["Ani", "Budi", "Citra", "Doni"],
    "Usia": [20, np.nan, 19, 22],
    "Nilai": [80, 90, np.nan, 85]
})

print(df.isna())
print(df.isna().sum())
print(df.isna().mean() * 100)

isna().sum() menghitung jumlah nilai yang hilang pada setiap kolom, sedangkan isna().mean() * 100 menghitung persentasenya.

b. Menghapus missing values

# Menghapus baris yang memiliki setidaknya satu nilai hilang
df_bersih = df.dropna()

# Menghapus baris jika kolom tertentu kosong
df_bersih = df.dropna(subset=["Usia"])

c. Mengisi missing values

# Mengisi usia dengan median
df["Usia"] = df["Usia"].fillna(
    df["Usia"].median()
)

# Mengisi nilai dengan mean
df["Nilai"] = df["Nilai"].fillna(
    df["Nilai"].mean()
)

Pemilihan metode pengisian bergantung pada makna data, distribusi, dan penyebab nilai hilang. Penghapusan atau pengisian tidak boleh dilakukan secara otomatis tanpa mempertimbangkan dampaknya. Untuk machine learning, parameter imputasi sebaiknya dipelajari dari data pelatihan saja agar tidak terjadi kebocoran informasi dari data validasi atau pengujian.

d. Memeriksa dan menghapus duplikasi

print(df.duplicated())
print("Jumlah duplikasi:", df.duplicated().sum())

# Menghapus baris yang sepenuhnya duplikat
df = df.drop_duplicates()

# Memeriksa duplikasi berdasarkan kolom tertentu
duplikat_nama = df[df.duplicated(subset=["Nama"])]

print(duplikat_nama)

Baris yang memiliki nama sama belum tentu merupakan duplikasi yang sebenarnya. Tentukan kunci unik berdasarkan konteks, misalnya ID transaksi atau kombinasi ID pelanggan dan waktu transaksi.

10. Transformasi dan Ekspor Data

Transformasi data mengubah bentuk, tipe, skala, atau representasi data agar sesuai untuk analisis. Setelah pengolahan selesai, hasil dapat disimpan kembali ke format berkas yang diperlukan.

a. Mengubah tipe data

import pandas as pd

df = pd.DataFrame({
    "Usia": ["20", "21", "19"],
    "Nilai": ["80", "90", "75"]
})

df["Usia"] = pd.to_numeric(df["Usia"])
df["Nilai"] = pd.to_numeric(df["Nilai"])

print(df.dtypes)

Fungsi to_numeric() mengubah nilai menjadi tipe numerik. Jika data mengandung nilai yang tidak dapat dikonversi, parameter errors="coerce" dapat digunakan untuk mengubah nilai tersebut menjadi missing values.

b. Membuat kolom baru

df["Lulus"] = df["Nilai"] >= 80

df["Kategori"] = df["Nilai"].apply(
    lambda x: "Tinggi" if x >= 85
    else "Sedang" if x >= 75
    else "Rendah"
)

print(df)

c. Normalisasi sederhana

Min-max scaling mengubah nilai numerik ke rentang 0 sampai 1, selama nilai maksimum dan minimum berbeda.

\[ x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}} \] 
nilai_min = df["Nilai"].min()
nilai_max = df["Nilai"].max()

if nilai_max != nilai_min:
    df["Nilai_Normal"] = (
        (df["Nilai"] - nilai_min) /
        (nilai_max - nilai_min)
    )
else:
    df["Nilai_Normal"] = 0.0

print(df)

Pada proyek machine learning, nilai minimum dan maksimum untuk scaling perlu dihitung dari data pelatihan saja, kemudian digunakan kembali untuk data validasi dan pengujian.

d. Mengganti nama dan menghapus kolom

df = df.rename(columns={
    "Nilai": "Nilai_Ujian"
})

df = df.drop(columns=["Kategori"])

print(df)

e. Mengekspor data ke CSV

df.to_csv(
    "data_bersih.csv",
    index=False
)

f. Mengekspor data ke Excel dan JSON

# Excel
df.to_excel(
    "data_bersih.xlsx",
    index=False
)

# JSON
df.to_json(
    "data_bersih.json",
    orient="records",
    indent=2,
    force_ascii=False
)

Parameter index=False mencegah indeks DataFrame disimpan sebagai kolom tambahan pada CSV atau Excel. Pilih format ekspor berdasarkan kebutuhan penggunaan data berikutnya.

11. Contoh Proyek Mini: Membersihkan Data Penjualan

Pada contoh berikut, beberapa teknik pengolahan data digabungkan dalam satu alur kerja sederhana. 

import pandas as pd

data = {
    "Tanggal": [
        "2026-01-05",
        "2026-01-10",
        "2026-02-02",
        "2026-02-15",
        "2026-02-15"
    ],
    "Produk": [
        "Laptop",
        "Mouse",
        "Laptop",
        "Keyboard",
        "Keyboard"
    ],
    "Jumlah": [2, 5, 1, 3, 3],
    "Harga": [8000000, 150000, 8000000, 400000, 400000]
}

df = pd.DataFrame(data)

# Menghapus baris duplikat
df = df.drop_duplicates()

# Memastikan tipe data
df["Tanggal"] = pd.to_datetime(df["Tanggal"])
df["Jumlah"] = pd.to_numeric(df["Jumlah"])
df["Harga"] = pd.to_numeric(df["Harga"])

# Menghitung total transaksi
df["Total"] = df["Jumlah"] * df["Harga"]

# Menghitung penjualan per produk
penjualan_produk = (
    df.groupby("Produk")["Total"]
      .sum()
      .sort_values(ascending=False)
)

print(penjualan_produk)

# Menyimpan hasil
df.to_csv("penjualan_bersih.csv", index=False)

Alur proyek tersebut meliputi pembuatan DataFrame, penghapusan duplikasi, konversi tipe data, penambahan kolom hasil perhitungan, agregasi, dan ekspor. Dalam proyek nyata, duplikasi harus diverifikasi terlebih dahulu agar transaksi sah tidak ikut terhapus.

Tahapan tersebut merupakan bagian penting dari preprocessing data. Data yang telah diperiksa dan dibersihkan dapat digunakan untuk eksplorasi data, visualisasi, analisis statistik, dan pembangunan model machine learning.
