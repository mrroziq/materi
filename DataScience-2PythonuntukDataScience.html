Python untuk Data Science

Python merupakan bahasa pemrograman yang banyak digunakan dalam data science karena memiliki sintaks yang relatif sederhana serta didukung berbagai pustaka untuk pengolahan, analisis, visualisasi, dan pemodelan data. Pada bagian ini, kita akan mempelajari dasar-dasar Python sebagai fondasi untuk memahami proses analisis data.

Tujuan Pembelajaran

Setelah mempelajari materi ini, mahasiswa diharapkan mampu:

  • Menggunakan variabel dan tipe data Python.
  • Menyusun ekspresi menggunakan operator.
  • Mengendalikan alur program dengan percabangan dan perulangan.
  • Mengolah data menggunakan struktur data bawaan Python.
  • Membuat fungsi dan menyusun program secara modular.
  • Membaca dan menulis file serta menangani kesalahan program.
  • Menggunakan library dan lingkungan kerja Python.
  • Menjalankan kode Python melalui Jupyter Notebook dan Google Colab.

1. Variabel dan Tipe Data

1.1 Variabel

Variabel adalah nama yang digunakan untuk merujuk pada suatu nilai atau objek di dalam program. Variabel dibuat melalui operasi penugasan menggunakan tanda sama dengan (=). 

nama = "Andi"
umur = 20
tinggi = 170.5
mahasiswa = True

print(nama)
print(umur)
print(tinggi)
print(mahasiswa)

Python tidak mengharuskan kita menuliskan tipe data ketika membuat variabel. Tipe data ditentukan berdasarkan objek yang diberikan kepada variabel.

1.2 Aturan Penamaan Variabel

  • Nama variabel dapat mengandung huruf, angka, dan garis bawah.
  • Nama variabel tidak boleh diawali angka.
  • Nama variabel tidak boleh mengandung spasi.
  • Huruf besar dan kecil dibedakan.
  • Kata kunci Python tidak boleh digunakan sebagai nama variabel.
nilai_matematika = 90
nilai2 = 85

# Contoh nama yang tidak valid:
# 2nilai = 85
# nilai matematika = 90

1.3 Tipe Data Dasar

Beberapa tipe data dasar yang sering digunakan adalah:

  • int: bilangan bulat, misalnya 10.
  • float: bilangan desimal, misalnya 3.14.
  • str: teks, misalnya "Python".
  • bool: nilai logika, yaitu True atau False.
  • NoneType: menyatakan ketiadaan nilai, yaitu None.
a = 10
b = 3.14
c = "Data Science"
d = True
e = None

print(type(a))
print(type(b))
print(type(c))
print(type(d))
print(type(e))

1.4 Konversi Tipe Data

Konversi tipe data digunakan untuk mengubah nilai dari satu tipe ke tipe lainnya, misalnya dari teks menjadi bilangan bulat. 

angka_teks = "25"
angka = int(angka_teks)

desimal = float("3.5")
teks = str(100)

print(angka + 5)
print(desimal)
print(teks)

Perlu diperhatikan bahwa tidak semua nilai dapat dikonversi secara langsung. Contohnya, int("halo") menghasilkan kesalahan karena teks tersebut bukan representasi bilangan bulat yang valid.

Contoh Soal

Perhatikan program berikut.

x = "10"
y = 5

print(int(x) + y)
print(type(x))
print(type(int(x)))

Penyelesaian:

  • Baris pertama mencetak 15.
  • Baris kedua mencetak <class 'str'>.
  • Baris ketiga mencetak <class 'int'>.

Fungsi int(x) mengonversi nilai x menjadi bilangan bulat tanpa mengubah tipe asli variabel x.

2. Operator dan Ekspresi

2.1 Operator Aritmetika

Operator aritmetika digunakan untuk melakukan perhitungan matematis.

  • +: penjumlahan.
  • -: pengurangan.
  • *: perkalian.
  • /: pembagian biasa.
  • //: pembagian dengan pembulatan ke bawah.
  • %: sisa pembagian.
  • **: perpangkatan.
a = 17
b = 5

print(a + b)   # 22
print(a - b)   # 12
print(a * b)   # 85
print(a / b)   # 3.4
print(a // b)  # 3
print(a % b)   # 2
print(a ** b)  # 1419857

2.2 Operator Perbandingan

Operator perbandingan membandingkan dua nilai dan menghasilkan nilai logika True atau False.

  • ==: sama dengan.
  • !=: tidak sama dengan.
  • >: lebih besar dari.
  • <: lebih kecil dari.
  • >=: lebih besar dari atau sama dengan.
  • <=: lebih kecil dari atau sama dengan.
nilai = 85

print(nilai >= 75)  # True
print(nilai == 100) # False
print(nilai != 0)   # True

2.3 Operator Logika

Operator logika menggabungkan atau membalikkan kondisi.

  • and: bernilai benar jika kedua kondisi benar.
  • or: bernilai benar jika minimal satu kondisi benar.
  • not: membalikkan nilai logika.
nilai = 85
kehadiran = 90

lulus = nilai >= 75 and kehadiran >= 80
istimewa = nilai >= 90 or kehadiran >= 95

print(lulus)      # True
print(istimewa)   # False
print(not lulus)  # False

2.4 Operator Penugasan

Operator penugasan digunakan untuk memberikan nilai atau memperbarui nilai suatu variabel. 

x = 10
x += 5   # x = x + 5
x -= 3   # x = x - 3
x *= 2   # x = x * 2

print(x) # 24

2.5 Ekspresi dan Prioritas Operator

Ekspresi adalah kombinasi nilai, variabel, dan operator yang menghasilkan suatu nilai. Python mengikuti prioritas operator tertentu, seperti perkalian yang dikerjakan sebelum penjumlahan. 

hasil1 = 2 + 3 * 4
hasil2 = (2 + 3) * 4

print(hasil1)  # 14
print(hasil2)  # 20

Penggunaan tanda kurung membantu memperjelas urutan operasi, terutama ketika ekspresi menjadi kompleks.

Contoh Soal

Tentukan hasil ekspresi berikut.

hasil = (20 - 4) / 2 ** 2 + 3
print(hasil)

Penyelesaian:

Pangkat dihitung terlebih dahulu, kemudian operasi di dalam kurung, pembagian, dan penjumlahan.

\[ \frac{20-4}{2^2}+3 =\frac{16}{4}+3=7 \]

Jadi, program mencetak 7.0.

3. Percabangan (if, elif, else)

3.1 Konsep Percabangan

Percabangan memungkinkan program memilih tindakan berdasarkan kondisi tertentu. Python menggunakan if, elif, dan else.

3.2 Pernyataan if

Pernyataan if menjalankan blok kode ketika kondisi bernilai benar. 

nilai = 85

if nilai >= 75:
    print("Lulus")

Tanda titik dua menandai awal blok kode, sedangkan indentasi menunjukkan kode yang termasuk dalam blok tersebut. Python umumnya menggunakan empat spasi.

3.3 Pernyataan if-else

Pernyataan else dijalankan ketika kondisi pada if tidak terpenuhi. 

nilai = 60

if nilai >= 75:
    print("Lulus")
else:
    print("Tidak lulus")

3.4 Pernyataan if-elif-else

elif digunakan untuk memeriksa kondisi alternatif apabila kondisi sebelumnya tidak terpenuhi. 

nilai = 82

if nilai >= 90:
    print("A")
elif nilai >= 80:
    print("B")
elif nilai >= 70:
    print("C")
elif nilai >= 60:
    print("D")
else:
    print("E")

Program tersebut mencetak B. Pemeriksaan dilakukan dari atas ke bawah dan blok pertama yang kondisinya benar akan dijalankan.

3.5 Percabangan Bersarang

Percabangan bersarang adalah percabangan yang ditempatkan di dalam blok percabangan lainnya. 

nilai = 85
kehadiran = 90

if nilai >= 75:
    if kehadiran >= 80:
        print("Lulus dengan syarat lengkap")
    else:
        print("Nilai cukup, kehadiran kurang")
else:
    print("Tidak lulus")

Contoh Soal

Sebuah program menentukan kategori data berdasarkan nilai pengukuran. Jika nilai negatif, tampilkan "Tidak valid". Jika nol, tampilkan "Nol". Selain itu, tampilkan "Positif". 

x = -3

if x < 0:
    print("Tidak valid")
elif x == 0:
    print("Nol")
else:
    print("Positif")

Karena \(x=-3\), keluaran program adalah Tidak valid.

4. Perulangan (for, while)

4.1 Konsep Perulangan

Perulangan digunakan untuk menjalankan suatu blok kode berkali-kali. Dua bentuk perulangan utama dalam Python adalah for dan while.

4.2 Perulangan for

Perulangan for digunakan untuk menelusuri elemen dalam suatu objek yang dapat diiterasi, seperti list, tuple, string, atau objek rentang. 

for i in range(5):
    print(i)

Hasilnya adalah angka 0 sampai 4.

Fungsi range() dapat menerima tiga argumen: nilai awal, batas akhir eksklusif, dan langkah. 

for i in range(2, 11, 2):
    print(i)

Hasilnya adalah 2, 4, 6, 8, dan 10.

4.3 Menghitung Jumlah Data

Perulangan dapat digunakan untuk menjumlahkan sekumpulan data secara bertahap. 

data = [10, 20, 30, 40]
total = 0

for angka in data:
    total += angka

print(total)  # 100

4.4 Perulangan while

Perulangan while menjalankan blok kode selama kondisi bernilai benar. 

i = 1

while i <= 5:
    print(i)
    i += 1

Variabel i diperbarui pada setiap iterasi sehingga kondisi akhirnya menjadi salah dan perulangan berhenti.

4.5 break dan continue

  • break menghentikan perulangan secara langsung.
  • continue melewati sisa kode pada iterasi saat ini dan melanjutkan ke iterasi berikutnya.
for i in range(1, 10):
    if i == 5:
        break
    print(i)

Program mencetak angka 1 sampai 4.

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Program mencetak 1, 2, 4, dan 5.

4.6 Perulangan Bersarang

Perulangan bersarang adalah perulangan di dalam perulangan lainnya. Struktur ini berguna untuk memproses data berbentuk tabel atau matriks. 

for i in range(1, 4):
    for j in range(1, 3):
        print(i, j)

Contoh Soal

Hitung jumlah bilangan genap dari 1 sampai 10 menggunakan perulangan. 

total = 0

for i in range(1, 11):
    if i % 2 == 0:
        total += i

print(total)

Bilangan genap yang dijumlahkan adalah \(2,4,6,8,10\). Dengan demikian,

\[ 2+4+6+8+10=30. \]

5. Struktur Data: list, tuple, set, dictionary

Struktur data digunakan untuk menyimpan dan mengatur sekumpulan nilai. Python menyediakan beberapa struktur data bawaan dengan karakteristik yang berbeda.

5.1 List

list adalah kumpulan elemen yang berurutan, dapat diubah, dan dapat mengandung elemen duplikat. List dibuat menggunakan tanda kurung siku. 

nilai = [80, 90, 75, 90]

print(nilai[0])   # 80
print(nilai[-1])  # 90

nilai.append(95)
nilai[0] = 85

print(nilai)

Indeks Python dimulai dari nol. Indeks negatif digunakan untuk mengakses elemen dari bagian akhir list.

Operasi list yang umum digunakan:

  • append(x): menambahkan elemen ke akhir.
  • insert(i, x): menyisipkan elemen pada indeks tertentu.
  • remove(x): menghapus kemunculan pertama nilai tertentu.
  • pop(i): menghapus dan mengembalikan elemen pada indeks tertentu.
  • sort(): mengurutkan list secara langsung.
  • len(): menghitung banyak elemen.

5.2 Tuple

tuple adalah kumpulan elemen yang berurutan dan tidak dapat diubah setelah dibuat. Tuple biasanya ditulis menggunakan tanda kurung biasa. 

koordinat = (10, 20)

print(koordinat[0])
print(koordinat[1])

Tuple cocok untuk menyimpan data yang tidak seharusnya diubah, seperti koordinat atau pasangan nilai tetap. Tuple yang hanya memiliki satu elemen harus ditulis dengan koma, misalnya (5,).

5.3 Set

set adalah kumpulan elemen unik yang tidak memiliki urutan indeks. Set berguna untuk menghilangkan duplikasi dan melakukan operasi himpunan. 

data = [1, 2, 2, 3, 3, 3]
unik = set(data)

print(unik)

A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)  # Gabungan
print(A & B)  # Irisan
print(A - B)  # Selisih

Set kosong dibuat menggunakan set(), bukan {}, karena tanda {} digunakan untuk dictionary kosong.

5.4 Dictionary

dictionary menyimpan pasangan kunci dan nilai. Setiap kunci harus unik dan dapat digunakan untuk mengakses nilai yang berkaitan dengannya. 

mahasiswa = {
    "nama": "Andi",
    "umur": 20,
    "jurusan": "Matematika"
}

print(mahasiswa["nama"])
print(mahasiswa["umur"])

mahasiswa["umur"] = 21
mahasiswa["semester"] = 5

print(mahasiswa)

Dictionary juga menyediakan metode keys(), values(), items(), dan get(). Metode get() dapat digunakan untuk mengambil nilai tanpa langsung menghasilkan KeyError ketika kunci tidak ditemukan. 

print(mahasiswa.get("IPK", 0.0))

for kunci, nilai in mahasiswa.items():
    print(kunci, ":", nilai)

5.5 Perbandingan Struktur Data

Struktur Berurutan Dapat diubah Duplikat
List Ya Ya Ya
Tuple Ya Tidak Ya
Set Tidak memiliki indeks urutan Ya Tidak
Dictionary Mempertahankan urutan penyisipan Ya Kunci tidak boleh duplikat

Contoh Soal

Diberikan data nilai mahasiswa berikut. 

nilai = [80, 75, 90, 80, 85]

print(len(nilai))
print(sum(nilai) / len(nilai))
print(set(nilai))

Penyelesaian:

  • Banyak data adalah 5.
  • Rata-rata nilai adalah \(410/5=82\).
  • Set menyimpan nilai unik, yaitu 80, 75, 90, dan 85. Urutan tampilannya tidak dijamin.

6. Fungsi dan Modularisasi

6.1 Pengertian Fungsi

Fungsi adalah blok kode yang dirancang untuk melakukan tugas tertentu dan dapat dipanggil berulang kali. Fungsi membantu mengurangi pengulangan kode, meningkatkan keterbacaan, dan memudahkan pengujian.

6.2 Membuat Fungsi dengan def

Fungsi dibuat menggunakan kata kunci def, diikuti nama fungsi, parameter, dan blok kode. 

def sapa():
    print("Selamat belajar Python!")

sapa()

6.3 Parameter dan Argumen

Parameter merupakan variabel yang ditulis dalam definisi fungsi, sedangkan argumen adalah nilai yang diberikan ketika fungsi dipanggil. 

def luas_persegi_panjang(panjang, lebar):
    luas = panjang * lebar
    return luas

hasil = luas_persegi_panjang(10, 5)
print(hasil)  # 50

6.4 Pernyataan return

Pernyataan return mengembalikan hasil perhitungan kepada pemanggil fungsi. Fungsi yang tidak menjalankan return secara eksplisit menghasilkan nilai None. 

def rata_rata(data):
    if len(data) == 0:
        return None

    return sum(data) / len(data)

nilai = [80, 90, 70]
print(rata_rata(nilai))

6.5 Parameter Default dan Argumen Bernama

Parameter default memiliki nilai awal yang digunakan apabila argumen tidak diberikan. Argumen bernama memungkinkan pemanggil menentukan parameter berdasarkan namanya. 

def pangkat(angka, eksponen=2):
    return angka ** eksponen

print(pangkat(5))               # 25
print(pangkat(5, 3))            # 125
print(pangkat(angka=2, eksponen=4))  # 16

6.6 Modularisasi Program

Modularisasi adalah teknik membagi program menjadi bagian-bagian yang memiliki tanggung jawab tertentu. Fungsi dapat diletakkan dalam file Python terpisah yang kemudian diimpor menggunakan import.

Misalnya, file statistika.py berisi:

def rata_rata(data):
    return sum(data) / len(data)

def nilai_maksimum(data):
    return max(data)

File lain dapat menggunakan fungsi tersebut. 

import statistika

data = [70, 80, 90]

print(statistika.rata_rata(data))
print(statistika.nilai_maksimum(data))

Dengan modularisasi, kode lebih mudah digunakan kembali dan dipelihara.

Contoh Soal

Buat fungsi untuk menghitung varians populasi dari sekumpulan data numerik. Varians populasi didefinisikan sebagai

\[ \sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2. \] 

def varians_populasi(data):
    if len(data) == 0:
        raise ValueError("Data tidak boleh kosong")

    mean = sum(data) / len(data)
    jumlah = sum((x - mean) ** 2 for x in data)

    return jumlah / len(data)

print(varians_populasi([2, 4, 6]))

Rata-rata data adalah 4. Jumlah kuadrat selisih terhadap rata-rata adalah \(4+0+4=8\). Varians populasinya adalah \(8/3\), atau sekitar 2,67.

7. File Handling

7.1 Membuka File

File handling adalah proses membaca, membuat, dan menulis file melalui program. Python menyediakan fungsi open() untuk mengakses file.

Mode file yang umum digunakan:

  • "r": membaca file yang sudah ada.
  • "w": menulis file dan mengganti isi file jika sudah ada.
  • "a": menambahkan isi pada akhir file.
  • "x": membuat file baru dan gagal jika file sudah ada.
  • "b": mode biner, misalnya "rb".

7.2 Membaca File Teks

Penggunaan with disarankan karena file akan ditutup secara otomatis setelah blok kode selesai. 

with open("data.txt", "r", encoding="utf-8") as file:
    isi = file.read()

print(isi)

Selain read(), kita dapat menggunakan readline() untuk membaca satu baris atau melakukan iterasi langsung terhadap objek file.

7.3 Menulis File

with open("hasil.txt", "w", encoding="utf-8") as file:
    file.write("Hasil Analisis Data\n")
    file.write("Jumlah data: 100\n")

Mode "w" menimpa isi file yang sudah ada. Jika ingin menambahkan isi tanpa menghapus konten sebelumnya, gunakan mode "a".

7.4 Membaca dan Menulis CSV

CSV (Comma-Separated Values) adalah format file tabular yang banyak digunakan untuk menyimpan data. Python menyediakan modul bawaan csv. 

import csv

with open("mahasiswa.csv", "r", newline="", encoding="utf-8") as file:
    pembaca = csv.DictReader(file)

    for baris in pembaca:
        print(baris["nama"], baris["nilai"])

Contoh tersebut mengasumsikan file CSV mempunyai kolom nama dan nilai. Untuk menulis CSV, gunakan csv.DictWriter atau csv.writer. 

import csv

data = [
    {"nama": "Andi", "nilai": 85},
    {"nama": "Budi", "nilai": 90}
]

with open("hasil.csv", "w", newline="", encoding="utf-8") as file:
    kolom = ["nama", "nilai"]
    penulis = csv.DictWriter(file, fieldnames=kolom)

    penulis.writeheader()
    penulis.writerows(data)

7.5 File untuk Data Science

Dalam data science, data sering diperoleh dari CSV, JSON, Excel, basis data, atau API. Python dapat membaca berbagai format tersebut menggunakan modul bawaan maupun library tambahan seperti pandas. 

import pandas as pd

data = pd.read_csv("data.csv")

print(data.head())
print(data.info())

Kode tersebut membutuhkan library pandas dan file data.csv yang tersedia pada lokasi yang sesuai.

Contoh Soal

Buat program untuk menyimpan tiga nilai mahasiswa ke dalam file teks. 

nilai = [80, 85, 90]

with open("nilai.txt", "w", encoding="utf-8") as file:
    for n in nilai:
        file.write(f"{n}\n")

File nilai.txt berisi tiga baris: 80, 85, dan 90.

8. Exception Handling

8.1 Pengertian Exception

Exception adalah kondisi kesalahan yang terjadi ketika program dijalankan. Contohnya adalah pembagian dengan nol, akses kunci dictionary yang tidak tersedia, atau pembacaan file yang tidak ditemukan. 

angka = int("abc")

Program tersebut menghasilkan ValueError karena teks "abc" tidak dapat dikonversi menjadi bilangan bulat.

8.2 try dan except

Blok try berisi kode yang berpotensi menimbulkan exception, sedangkan except menentukan tindakan ketika exception tertentu terjadi. 

try:
    angka = int(input("Masukkan bilangan bulat: "))
    print(100 / angka)
except ValueError:
    print("Input harus berupa bilangan bulat.")
except ZeroDivisionError:
    print("Bilangan tidak boleh nol.")

8.3 else dan finally

  • else dijalankan jika blok try tidak menghasilkan exception.
  • finally dijalankan setelah proses try selesai, baik terjadi exception maupun tidak.
try:
    angka = int("25")
except ValueError:
    print("Konversi gagal")
else:
    print("Konversi berhasil:", angka)
finally:
    print("Proses selesai")

8.4 Menghasilkan Exception dengan raise

Kata kunci raise digunakan untuk menghasilkan exception secara sengaja, misalnya ketika suatu fungsi menerima argumen yang tidak valid. 

def hitung_rata_rata(data):
    if len(data) == 0:
        raise ValueError("Data tidak boleh kosong")

    return sum(data) / len(data)

print(hitung_rata_rata([80, 90, 100]))

Validasi tersebut membantu mencegah hasil perhitungan yang tidak bermakna. Exception yang sengaja dihasilkan tetap perlu ditangani jika program harus terus berjalan.

8.5 Prinsip Penanganan Kesalahan

  • Tangani jenis exception yang memang dapat diperkirakan.
  • Berikan pesan kesalahan yang jelas.
  • Hindari menangkap semua exception tanpa alasan.
  • Validasi masukan sebelum melakukan perhitungan.
  • Gunakan with untuk mengelola file dengan aman.

Contoh Soal

Buat fungsi pembagian yang menolak pembagi nol. 

def bagi(a, b):
    if b == 0:
        raise ZeroDivisionError("Pembagi tidak boleh nol")
    return a / b

try:
    print(bagi(10, 0))
except ZeroDivisionError as e:
    print("Kesalahan:", e)

Keluaran program adalah pesan kesalahan Kesalahan: Pembagi tidak boleh nol. Program tetap dapat melanjutkan proses setelah exception tersebut ditangani.

9. Library dan Virtual Environment

9.1 Modul, Library, dan Package

Modul adalah file Python yang dapat berisi fungsi, kelas, dan variabel. Package mengorganisasi modul dalam struktur direktori. Istilah library sering digunakan untuk menyebut kumpulan kode yang menyediakan fungsi tertentu.

Python memiliki modul bawaan seperti math, random, dan statistics. 

import math
import statistics

print(math.sqrt(81))
print(math.pi)

data = [70, 80, 90]
print(statistics.mean(data))
print(statistics.median(data))

9.2 Mengimpor Library

Modul dapat diimpor menggunakan beberapa bentuk sintaks. 

import math
print(math.sqrt(25))

from math import pi, sqrt
print(sqrt(36))
print(pi)

import statistics as stats
print(stats.mean([10, 20, 30]))

9.3 Library Penting untuk Data Science

  • NumPy: operasi numerik dan array multidimensi.
  • pandas: manipulasi data berbentuk tabel.
  • Matplotlib: pembuatan grafik dan visualisasi.
  • Seaborn: visualisasi statistik.
  • SciPy: komputasi ilmiah dan metode numerik.
  • scikit-learn: pemrosesan data dan machine learning.

Contoh penggunaan NumPy: 

import numpy as np

data = np.array([10, 20, 30, 40, 50])

print(np.mean(data))
print(np.std(data))
print(data * 2)

Contoh penggunaan pandas: 

import pandas as pd

data = {
    "nama": ["Andi", "Budi", "Citra"],
    "nilai": [80, 90, 85]
}

df = pd.DataFrame(data)

print(df)
print(df["nilai"].mean())

9.4 Instalasi Library dengan pip

pip adalah alat untuk menginstal dan mengelola package Python. Perintah berikut dijalankan pada terminal atau command prompt, bukan sebagai kode Python biasa. 

python -m pip install numpy pandas matplotlib seaborn scikit-learn

Untuk melihat package yang terpasang, gunakan: 

python -m pip list

9.5 Pengertian Virtual Environment

Virtual environment adalah lingkungan Python terisolasi yang memungkinkan setiap proyek memiliki package dan versi dependensi masing-masing. Penggunaan lingkungan terpisah membantu mengurangi konflik antarpaket.

9.6 Membuat Virtual Environment

Pada Windows:

python -m venv .venv
.venv\Scripts\activate

Pada Linux atau macOS:

python3 -m venv .venv
source .venv/bin/activate

Setelah lingkungan aktif, library dapat diinstal khusus untuk lingkungan tersebut. 

python -m pip install numpy pandas

Untuk menonaktifkan lingkungan, jalankan deactivate. Perintah aktivasi berbeda untuk setiap sistem operasi dan jenis shell.

9.7 Menyimpan Dependensi

Daftar package proyek dapat disimpan dalam file requirements.txt. 

python -m pip freeze > requirements.txt

Lingkungan lain dapat memasang dependensi dari file tersebut menggunakan: 

python -m pip install -r requirements.txt

Contoh Soal

Seorang mahasiswa mengerjakan dua proyek. Proyek A memerlukan versi library tertentu, sedangkan Proyek B menggunakan versi yang berbeda. Mengapa virtual environment bermanfaat?

Penyelesaian:

Setiap proyek dapat memiliki lingkungan terpisah sehingga versi library yang diperlukan tidak harus saling menggantikan. Hal ini memudahkan reproduksi eksperimen dan pengelolaan dependensi.

10. Jupyter Notebook dan Google Colab

10.1 Jupyter Notebook

Jupyter Notebook adalah lingkungan interaktif untuk menulis dan menjalankan kode, menampilkan hasil perhitungan, membuat visualisasi, serta menambahkan penjelasan. Dokumen notebook terdiri atas sel-sel yang dapat dijalankan secara terpisah.

Dua jenis sel yang paling umum adalah:

  • Code cell: menjalankan kode Python.
  • Markdown cell: menuliskan penjelasan, judul, daftar, dan rumus matematika.

10.2 Menjalankan Jupyter Notebook

Jupyter dapat diinstal dalam lingkungan Python melalui terminal. 

python -m pip install notebook
jupyter notebook

Setelah perintah dijalankan, antarmuka Jupyter biasanya dibuka melalui browser. Perintah instalasi tersebut dijalankan pada terminal setelah Python tersedia.

10.3 Menjalankan Kode dalam Sel

Misalnya, sel pertama berisi: 

angka = [10, 20, 30, 40, 50]
print(sum(angka))

Sel berikutnya dapat menggunakan variabel angka selama kernel yang sama masih aktif dan sel pembentuk variabel telah dijalankan. 

rata_rata = sum(angka) / len(angka)
print(rata_rata)

Urutan eksekusi sel dapat berbeda dari urutan tampilannya. Karena itu, jalankan sel secara teratur dan mulai ulang kernel apabila keadaan variabel menjadi tidak konsisten.

10.4 Google Colab

Google Colab adalah layanan notebook berbasis cloud yang memungkinkan pengguna menjalankan Python melalui browser. Colab dapat digunakan tanpa memasang lingkungan Python lokal dan mendukung integrasi dengan Google Drive.

Untuk memulai, buka Google Colab , buat notebook baru, kemudian jalankan kode pada sel menggunakan tombol eksekusi atau kombinasi Shift + Enter.

10.5 Menggunakan Library di Colab

Banyak library data science telah tersedia di Colab. Jika library tertentu belum tersedia, instal menggunakan perintah khusus notebook. 

%pip install numpy pandas matplotlib

Tanda % pada perintah tersebut merupakan sintaks khusus IPython, bukan sintaks Python standar yang dapat digunakan langsung pada semua file .py.

10.6 Membaca File CSV di Colab

Jika file CSV sudah tersedia di lingkungan notebook, file tersebut dapat dibaca menggunakan pandas. 

import pandas as pd

df = pd.read_csv("/content/data.csv")

display(df.head())
print(df.shape)
print(df.columns)

Jika file belum tersedia, unggah melalui panel Files atau gunakan fasilitas upload notebook. Untuk file yang tersimpan di Google Drive, pengguna juga dapat menghubungkan Drive terlebih dahulu.

10.7 Contoh Alur Analisis Data Sederhana

Berikut contoh alur kerja dasar yang menggabungkan Python, pandas, dan visualisasi data. 

import pandas as pd
import matplotlib.pyplot as plt

data = {
    "bulan": ["Januari", "Februari", "Maret", "April"],
    "penjualan": [120, 150, 135, 180]
}

df = pd.DataFrame(data)

print(df)
print("Rata-rata:", df["penjualan"].mean())
print("Penjualan tertinggi:", df["penjualan"].max())

df.plot(
    x="bulan",
    y="penjualan",
    kind="bar",
    legend=False
)

plt.title("Penjualan per Bulan")
plt.xlabel("Bulan")
plt.ylabel("Jumlah Penjualan")
plt.tight_layout()
plt.show()

Program tersebut membuat tabel penjualan, menghitung rata-rata, mencari nilai maksimum, dan menghasilkan diagram batang. Contoh ini menggunakan data buatan untuk memperkenalkan alur analisis data.

10.8 Jupyter Notebook vs Google Colab

Aspek Jupyter Notebook lokal Google Colab
Instalasi Umumnya perlu instalasi lokal Dijalankan melalui browser
Komputasi Menggunakan sumber daya komputer lokal Menggunakan runtime cloud yang tersedia
File Dapat mengakses file lokal File perlu diunggah atau dihubungkan
Penggunaan Cocok untuk pengembangan lokal Cocok untuk pembelajaran dan eksperimen cloud

Pilihan lingkungan kerja bergantung pada kebutuhan proyek, sumber daya komputasi, akses internet, serta pengelolaan file dan dependensi.

Contoh Soal

Sebuah dataset berisi nilai ujian 70, 80, 90, 85, dan 75. Tuliskan program untuk menghitung rata-rata dan menampilkan grafik sederhana di notebook. 

import pandas as pd
import matplotlib.pyplot as plt

nilai = [70, 80, 90, 85, 75]

df = pd.DataFrame({"nilai": nilai})

print("Rata-rata:", df["nilai"].mean())

df["nilai"].plot(kind="line", marker="o")
plt.title("Nilai Ujian Mahasiswa")
plt.xlabel("Indeks Mahasiswa")
plt.ylabel("Nilai")
plt.show()

Rata-rata nilai adalah \[ \bar{x} = \frac{70+80+90+85+75}{5}=80. \] Grafik menampilkan nilai setiap mahasiswa berdasarkan urutan datanya.

Rangkuman

  • Variabel menyimpan referensi nilai, sedangkan tipe data menentukan karakteristik objek yang digunakan.
  • Operator digunakan untuk perhitungan, perbandingan, logika, dan penugasan.
  • Percabangan memilih tindakan berdasarkan kondisi, sedangkan perulangan mengulang instruksi.
  • List, tuple, set, dan dictionary memiliki karakteristik penyimpanan yang berbeda.
  • Fungsi dan modularisasi membantu menghasilkan program yang terstruktur dan dapat digunakan kembali.
  • File handling memungkinkan program membaca serta menulis data.
  • Exception handling membantu mengelola kesalahan ketika program berjalan.
  • Library menyediakan fungsi siap pakai, sementara virtual environment membantu mengisolasi dependensi proyek.
  • Jupyter Notebook dan Google Colab menyediakan lingkungan interaktif untuk eksplorasi dan analisis data.
