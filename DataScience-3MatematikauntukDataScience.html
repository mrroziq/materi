1. Aljabar dan Fungsi

1.1 Variabel dan Konstanta

Variabel adalah simbol yang nilainya dapat berubah, sedangkan konstanta merupakan nilai yang dianggap tetap dalam suatu konteks. Dalam matematika, variabel digunakan untuk menyatakan hubungan antarbesaran.

Contoh ekspresi aljabar:

\[ 3x+5,\qquad 2x^2-4x+7. \]

Jika \(x=2\), maka nilai \(3x+5\) adalah \(3(2)+5=11\).

1.2 Operasi Aljabar

Operasi aljabar meliputi penjumlahan, pengurangan, perkalian, pembagian, dan perpangkatan. Operasi ini mengikuti sifat komutatif, asosiatif, dan distributif sesuai dengan jenis operasinya.

Sifat distributif:

\[ a(b+c)=ab+ac. \]

Contoh:

\[ 3(x+4)=3x+12. \]

1.3 Pengertian Fungsi

Fungsi adalah aturan yang memasangkan setiap elemen domain dengan tepat satu elemen kodomain. Fungsi dinyatakan dengan notasi \(f:X\to Y\).

Contoh fungsi linear:

\[ f(x)=2x+3. \]

Untuk \(x=4\), diperoleh \(f(4)=2(4)+3=11\).

1.4 Domain dan Range

Domain adalah himpunan masukan yang diperbolehkan, sedangkan range adalah himpunan nilai keluaran yang benar-benar dihasilkan fungsi.

Contoh:

\[ f(x)=\frac{1}{x-2}. \]

Penyebut tidak boleh nol sehingga domainnya adalah semua bilangan real kecuali \(x=2\). Range-nya juga semua bilangan real kecuali nol.

1.5 Jenis Fungsi

  • Fungsi linear: \(f(x)=ax+b\).
  • Fungsi kuadrat: \(f(x)=ax^2+bx+c\).
  • Fungsi polinomial: \(f(x)=a_nx^n+\cdots+a_1x+a_0\).
  • Fungsi rasional: \(f(x)=p(x)/q(x)\), dengan \(q(x)\neq0\).
  • Fungsi potongan: aturan fungsi berbeda pada interval yang berbeda.

1.6 Komposisi Fungsi

Komposisi fungsi menggabungkan dua fungsi sehingga keluaran fungsi pertama menjadi masukan fungsi kedua.

\[ (f\circ g)(x)=f(g(x)). \]

Jika \(f(x)=2x+1\) dan \(g(x)=x^2\), maka

\[ (f\circ g)(x)=2x^2+1. \]

1.7 Penerapan dalam Data Science

Fungsi digunakan untuk merepresentasikan hubungan antara fitur dan keluaran. Contohnya, fungsi linear dapat digunakan untuk memperkirakan harga rumah berdasarkan luas bangunan. 

def prediksi_harga(luas):
    return 2_000_000 * luas + 100_000_000

print(prediksi_harga(100))

Contoh Soal

Diberikan fungsi \(f(x)=3x^2-2x+1\). Tentukan \(f(2)\).

Penyelesaian:

\[ f(2)=3(2)^2-2(2)+1=12-4+1=9. \]

Jadi, \(f(2)=9\).

2. Persamaan dan Pertidaksamaan

2.1 Persamaan Linear

Persamaan linear satu variabel dapat ditulis dalam bentuk \(ax+b=0\), dengan \(a\neq0\).

\[ ax+b=0 \quad\Longrightarrow\quad x=-\frac{b}{a}. \]

Contoh:

\[ 3x+6=0 \quad\Longrightarrow\quad x=-2. \]

2.2 Persamaan Kuadrat

Persamaan kuadrat berbentuk \(ax^2+bx+c=0\), dengan \(a\neq0\). Penyelesaiannya dapat diperoleh menggunakan pemfaktoran atau rumus kuadrat.

\[ x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}. \]

Diskriminan \(D=b^2-4ac\) menentukan jenis akar real: dua akar berbeda jika \(D>0\), satu akar real kembar jika \(D=0\), dan tidak ada akar real jika \(D<0\).

2.3 Pertidaksamaan

\[ 2x+4>10 \quad\Longrightarrow\quad x>3. \]

\[ -2x>6 \quad\Longrightarrow\quad x<-3. \]

\[ f(x)=a^x,\qquad a>0,\ a\neq1. \]

Jika \(a>1\), fungsi meningkat. Jika \(0

3.2 Sifat Eksponen

\[ a^m a^n=a^{m+n}, \qquad \frac{a^m}{a^n}=a^{m-n}, \]

\[ (a^m)^n=a^{mn}, \qquad a^0=1. \]

3.3 Fungsi Logaritma

Logaritma merupakan operasi invers dari eksponensial.

\[ y=\log_a x \quad\Longleftrightarrow\quad a^y=x. \]

Syaratnya adalah \(a>0\), \(a\neq1\), dan \(x>0\). Logaritma natural ditulis \(\ln x\) dan memiliki basis \(e\).

3.4 Sifat Logaritma

\[ \log_a(xy)=\log_a x+\log_a y, \]

\[ \log_a\left(\frac{x}{y}\right) =\log_a x-\log_a y, \]

4. Limit dan Turunan

4.1 Konsep Limit

Limit menggambarkan nilai yang didekati suatu fungsi ketika variabel mendekati nilai tertentu.

\[ \lim_{x\to a}f(x)=L. \]

Limit tidak selalu sama dengan nilai fungsi di titik tersebut. Limit dapat tetap ada meskipun fungsi tidak terdefinisi pada titik yang dituju.

4.2 Sifat Limit

Jika limit-limit berikut ada, maka

\[ \lim_{x\to a}[f(x)+g(x)] = \lim_{x\to a}f(x)+\lim_{x\to a}g(x). \]

\[ \lim_{x\to a}[f(x)g(x)] = \left(\lim_{x\to a}f(x)\right) \left(\lim_{x\to a}g(x)\right). \]

4.3 Definisi Turunan

Turunan mengukur laju perubahan sesaat suatu fungsi. Turunan juga menyatakan kemiringan garis singgung grafik pada suatu titik.

\[ f'(x)= \lim_{h\to0} \frac{f(x+h)-f(x)}{h}. \]

4.4 Aturan Turunan

\[ \frac{d}{dx}x^n=nx^{n-1}. \]

\[ \frac{d}{dx}[af(x)+bg(x)] =af'(x)+bg'(x). \]

\[ \frac{d}{dx}[f(x)g(x)] =f'(x)g(x)+f(x)g'(x). \]

\[ \frac{d}{dx}\left(\frac{f(x)}{g(x)}\right) = \frac{f'(x)g(x)-f(x)g'(x)}{g(x)^2}. \]

4.5 Aturan Rantai

Jika \(y=f(g(x))\), maka

\[ \frac{dy}{dx}=f'(g(x))g'(x). \]

4.6 Penerapan Turunan

Turunan digunakan untuk menentukan laju perubahan, mencari titik kritis, dan memecahkan masalah optimisasi. Dalam machine learning, turunan menjadi dasar pembaruan parameter model. 

import sympy as sp

x = sp.symbols("x")
f = x**3 - 3*x**2 + 2

turunan = sp.diff(f, x)

print(turunan)
print(turunan.subs(x, 2))

Contoh tersebut menggunakan SymPy untuk menghitung turunan simbolik. Library dapat dipasang dengan python -m pip install sympy.

Contoh Soal

Tentukan turunan \(f(x)=x^3+2x^2-5x+1\).

Penyelesaian:

\[ f'(x)=3x^2+4x-5. \]

Pada \(x=2\), diperoleh \(f'(2)=12+8-5=15\).

5. Integral Dasar

5.1 Pengertian Integral

Integral tak tentu berkaitan dengan pencarian antiturunan. Jika \(F'(x)=f(x)\), maka

\[ \int f(x)\,dx=F(x)+C, \]

dengan \(C\) sebagai konstanta integrasi.

5.2 Aturan Integral Dasar

\[ \int x^n\,dx =\frac{x^{n+1}}{n+1}+C, \qquad n\neq-1. \]

\[ \int \frac{1}{x}\,dx=\ln|x|+C. \]

\[ \int e^x\,dx=e^x+C. \]

\[ \int \cos x\,dx=\sin x+C. \]

5.3 Integral Tentu

Integral tentu menghitung akumulasi bertanda suatu fungsi pada interval tertentu. Berdasarkan Teorema Dasar Kalkulus,

\[ \int_a^b f(x)\,dx=F(b)-F(a), \]

dengan \(F'(x)=f(x)\), jika fungsi memenuhi syarat yang diperlukan.

5.4 Penerapan Integral

Integral digunakan dalam penghitungan luas, akumulasi, nilai harapan untuk variabel acak kontinu, dan interpretasi fungsi kepadatan probabilitas. 

import sympy as sp

x = sp.symbols("x")
f = x**2

integral_tak_tentu = sp.integrate(f, x)
integral_tentu = sp.integrate(f, (x, 0, 3))

print(integral_tak_tentu)
print(integral_tentu)

Contoh Soal

Hitung \(\int_0^2 (3x^2+1)\,dx\).

Penyelesaian:

\[ \int (3x^2+1)\,dx=x^3+x+C. \]

\[ \int_0^2(3x^2+1)\,dx =[x^3+x]_0^2=8+2=10. \]

6. Vektor dan Matriks

6.1 Pengertian Vektor

Vektor adalah objek matematika yang memiliki komponen dan dapat merepresentasikan posisi, arah, atau kumpulan fitur numerik.

\[ \mathbf{x}= \begin{bmatrix} x_1\\x_2\\ \vdots\\x_n \end{bmatrix}. \]

Dalam data science, satu observasi sering direpresentasikan sebagai vektor fitur. Misalnya, sebuah rumah dapat direpresentasikan oleh luas bangunan, jumlah kamar, dan usia bangunan.

6.2 Operasi Vektor

Dua vektor dengan dimensi sama dapat dijumlahkan berdasarkan komponennya.

\[ \mathbf{a}+\mathbf{b} = \begin{bmatrix} a_1+b_1\\a_2+b_2 \end{bmatrix}. \]

Perkalian titik atau dot product didefinisikan sebagai

\[ \mathbf{a}\cdot\mathbf{b} =\sum_{i=1}^{n}a_ib_i. \]

6.3 Pengertian Matriks

Matriks adalah susunan elemen dalam baris dan kolom. Matriks berukuran \(m\times n\) memiliki \(m\) baris dan \(n\) kolom.

\[ A= \begin{bmatrix} 1&2&3\\ 4&5&6 \end{bmatrix}. \]

Matriks tersebut berukuran \(2\times3\). Dalam data science, dataset tabular dapat direpresentasikan sebagai matriks dengan baris sebagai observasi dan kolom sebagai fitur numerik.

6.4 Transpos Matriks

Transpos matriks menukar baris dan kolom.

\[ A= \begin{bmatrix}1&2\\3&4\end{bmatrix}, \qquad A^T= \begin{bmatrix}1&3\\2&4\end{bmatrix}. \]

6.5 Implementasi dengan NumPy

import numpy as np

v = np.array([1, 2, 3])
w = np.array([4, 5, 6])

A = np.array([
    [1, 2],
    [3, 4]
])

print(v + w)
print(np.dot(v, w))
print(A.T)
print(A.shape)

Contoh Soal

Diberikan

\[ \mathbf{a}=(1,2,3),\qquad \mathbf{b}=(4,0,-1). \]

Hitung \(\mathbf{a}\cdot\mathbf{b}\).

Penyelesaian:

\[ \mathbf{a}\cdot\mathbf{b} =1(4)+2(0)+3(-1)=1. \]

7. Operasi Matriks dan Invers

7.1 Penjumlahan Matriks

Dua matriks dapat dijumlahkan jika ukurannya sama. Penjumlahan dilakukan pada elemen yang bersesuaian.

\[ \begin{bmatrix}1&2\\3&4\end{bmatrix} + \begin{bmatrix}5&6\\7&8\end{bmatrix} = \begin{bmatrix}6&8\\10&12\end{bmatrix}. \]

7.2 Perkalian Skalar dan Matriks

Perkalian skalar mengalikan setiap elemen matriks dengan suatu bilangan.

\[ 2\begin{bmatrix}1&2\\3&4\end{bmatrix} = \begin{bmatrix}2&4\\6&8\end{bmatrix}. \]

7.3 Perkalian Matriks

Jika \(A\) berukuran \(m\times n\) dan \(B\) berukuran \(n\times p\), maka \(AB\) terdefinisi dan berukuran \(m\times p\).

\[ (AB)_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}. \]

Perkalian matriks pada umumnya tidak komutatif: \(AB\neq BA\).

7.4 Determinan

Determinan adalah nilai skalar yang terkait dengan matriks persegi. Untuk matriks berukuran \(2\times2\),

\[ A=\begin{bmatrix}a&b\\c&d\end{bmatrix}, \qquad \det(A)=ad-bc. \]

7.5 Invers Matriks

Invers matriks \(A\), ditulis \(A^{-1}\), memenuhi

\[ AA^{-1}=A^{-1}A=I. \]

Invers hanya ada untuk matriks persegi yang nonsingular, yaitu matriks dengan determinan tidak nol. Untuk matriks berukuran \(2\times2\),

\[ A^{-1}= \frac{1}{ad-bc} \begin{bmatrix}d&-b\\-c&a\end{bmatrix}, \qquad ad-bc\neq0. \]

7.6 Implementasi dengan NumPy

import numpy as np

A = np.array([
    [2, 1],
    [1, 3]
])

print("Determinan:", np.linalg.det(A))
print("Invers:")
print(np.linalg.inv(A))

B = np.array([
    [1, 2],
    [3, 4]
])

print("Perkalian matriks:")
print(A @ B)

Untuk komputasi numerik, gunakan fungsi pada numpy.linalg. Pada persoalan sistem linear, menyelesaikan sistem secara langsung umumnya lebih baik daripada menghitung invers secara eksplisit.

Contoh Soal

Tentukan invers matriks

\[ A=\begin{bmatrix}2&1\\1&3\end{bmatrix}. \]

Penyelesaian:

\[ \det(A)=2(3)-1(1)=5. \]

Karena determinannya tidak nol, invers ada.

\[ A^{-1}=\frac15 \begin{bmatrix}3&-1\\-1&2\end{bmatrix}. \]

8. Sistem Persamaan Linear

8.1 Bentuk Matriks

Sistem persamaan linear merupakan sekumpulan persamaan yang memiliki variabel-variabel bersama. Sistem tersebut dapat ditulis dalam bentuk

\[ A\mathbf{x}=\mathbf{b}, \]

dengan \(A\) sebagai matriks koefisien, \(\mathbf{x}\) sebagai vektor variabel, dan \(\mathbf{b}\) sebagai vektor konstanta.

8.2 Contoh Sistem Dua Variabel

\[ \begin{aligned} 2x+y&=5,\\ x-y&=1. \end{aligned} \]

Dalam bentuk matriks:

\[ \begin{bmatrix}2&1\\1&-1\end{bmatrix} \begin{bmatrix}x\\y\end{bmatrix} = \begin{bmatrix}5\\1\end{bmatrix}. \]

8.3 Metode Penyelesaian

  • Substitusi dan eliminasi.
  • Eliminasi Gauss.
  • Eliminasi Gauss-Jordan.
  • Metode invers, jika matriks koefisien invertibel.
  • Metode numerik untuk sistem berukuran besar.

8.4 Jenis Solusi

Sistem linear dapat memiliki:

  • Satu solusi, jika sistem konsisten dengan solusi tunggal.
  • Tak hingga banyak solusi, jika persamaan tidak menentukan semua variabel secara unik.
  • Tidak ada solusi, jika persamaan saling bertentangan.

8.5 Implementasi Python

import numpy as np

A = np.array([
    [2, 1],
    [1, -1]
], dtype=float)

b = np.array([5, 1], dtype=float)

solusi = np.linalg.solve(A, b)

print("x =", solusi[0])
print("y =", solusi[1])

Contoh Soal

Selesaikan sistem:

\[ \begin{aligned} 2x+y&=5,\\ x-y&=1. \end{aligned} \]

Penyelesaian:

Dari persamaan kedua, \(y=x-1\). Substitusi ke persamaan pertama menghasilkan

\[ 2x+(x-1)=5 \Longrightarrow 3x=6 \Longrightarrow x=2. \]

Oleh karena itu, \(y=2-1=1\). Solusinya adalah \((x,y)=(2,1)\).

9. Nilai Eigen dan Vektor Eigen

9.1 Definisi

Nilai eigen dan vektor eigen menggambarkan arah khusus suatu transformasi linear. Untuk matriks persegi \(A\), vektor tak nol \(\mathbf{v}\) merupakan vektor eigen jika

\[ A\mathbf{v}=\lambda\mathbf{v}, \]

dengan \(\lambda\) sebagai nilai eigen yang bersesuaian.

9.2 Persamaan Karakteristik

Nilai eigen diperoleh dari persamaan karakteristik

\[ \det(A-\lambda I)=0. \]

Setelah nilai eigen ditemukan, vektor eigennya diperoleh dengan menyelesaikan

\[ (A-\lambda I)\mathbf{v}=\mathbf{0}. \]

9.3 Contoh Perhitungan

Diberikan matriks

\[ A=\begin{bmatrix}2&0\\0&3\end{bmatrix}. \]

Persamaan karakteristiknya adalah

\[ \det(A-\lambda I) =(2-\lambda)(3-\lambda)=0. \]

Jadi, nilai eigennya adalah \(\lambda_1=2\) dan \(\lambda_2=3\). Vektor eigen yang bersesuaian dapat dipilih sebagai

\[ \mathbf{v}_1=\begin{bmatrix}1\\0\end{bmatrix}, \qquad \mathbf{v}_2=\begin{bmatrix}0\\1\end{bmatrix}. \]

9.4 Penerapan dalam Data Science

Nilai eigen dan vektor eigen digunakan dalam analisis komponen utama (Principal Component Analysis atau PCA), analisis struktur matriks, sistem dinamis, dan reduksi dimensi.

Pada PCA, vektor eigen dari matriks kovarians mengidentifikasi arah komponen utama, sedangkan nilai eigen menunjukkan besarnya varians yang terkait dengan masing-masing arah tersebut. 

import numpy as np

A = np.array([
    [2, 0],
    [0, 3]
], dtype=float)

nilai_eigen, vektor_eigen = np.linalg.eig(A)

print("Nilai eigen:")
print(nilai_eigen)

print("Vektor eigen:")
print(vektor_eigen)

Contoh Soal

Tunjukkan bahwa \(\mathbf{v}=(1,0)^T\) merupakan vektor eigen matriks \(A=\begin{bmatrix}4&0\\0&2\end{bmatrix}\).

Penyelesaian:

\[ A\mathbf{v} = \begin{bmatrix}4&0\\0&2\end{bmatrix} \begin{bmatrix}1\\0\end{bmatrix} = \begin{bmatrix}4\\0\end{bmatrix} =4\mathbf{v}. \]

Dengan demikian, \(\mathbf{v}\) adalah vektor eigen dengan nilai eigen \(\lambda=4\).

10. Kalkulus Multivariabel

10.1 Fungsi Banyak Variabel

Fungsi multivariabel memiliki lebih dari satu variabel bebas. Contohnya adalah fungsi

\[ f(x,y)=x^2+3xy+y^2. \]

Nilai fungsi bergantung pada pasangan masukan \((x,y)\). Fungsi semacam ini dapat digunakan untuk menggambarkan hubungan antara beberapa fitur dan suatu nilai keluaran.

10.2 Turunan Parsial

Turunan parsial mengukur laju perubahan fungsi terhadap satu variabel dengan variabel lainnya diperlakukan konstan.

\[ \frac{\partial f}{\partial x}, \qquad \frac{\partial f}{\partial y}. \]

Untuk \(f(x,y)=x^2+3xy+y^2\), diperoleh

\[ \frac{\partial f}{\partial x}=2x+3y, \]

\[ \frac{\partial f}{\partial y}=3x+2y. \]

10.3 Turunan Parsial Tingkat Dua

Turunan parsial dapat dihitung kembali untuk mempelajari perubahan laju perubahan.

\[ f_{xx}=\frac{\partial^2 f}{\partial x^2}, \qquad f_{yy}=\frac{\partial^2 f}{\partial y^2}. \]

Turunan campuran dinyatakan dengan \(f_{xy}\) dan \(f_{yx}\). Jika turunan campuran kontinu di sekitar titik yang ditinjau, keduanya sama.

10.4 Diferensial Total

Untuk fungsi \(z=f(x,y)\), diferensial total diberikan oleh

\[ dz=f_x\,dx+f_y\,dy. \]

Diferensial total dapat digunakan untuk mendekati perubahan fungsi akibat perubahan kecil pada beberapa variabel.

10.5 Implementasi Python

import sympy as sp

x, y = sp.symbols("x y")
f = x**2 + 3*x*y + y**2

fx = sp.diff(f, x)
fy = sp.diff(f, y)

print("Turunan terhadap x:", fx)
print("Turunan terhadap y:", fy)

print("Nilai fx di (1, 2):", fx.subs({x: 1, y: 2}))
print("Nilai fy di (1, 2):", fy.subs({x: 1, y: 2}))

Contoh Soal

Diberikan \(f(x,y)=x^2y+4y^3\). Tentukan turunan parsial terhadap \(x\) dan \(y\).

Penyelesaian:

\[ \frac{\partial f}{\partial x}=2xy, \]

\[ \frac{\partial f}{\partial y}=x^2+12y^2. \]

11. Gradien dan Optimisasi

11.1 Pengertian Gradien

Gradien merupakan vektor yang memuat turunan parsial pertama dari suatu fungsi multivariabel.

\[ \nabla f= \begin{bmatrix} \frac{\partial f}{\partial x_1}\\ \frac{\partial f}{\partial x_2}\\ \vdots\\ \frac{\partial f}{\partial x_n} \end{bmatrix}. \]

Gradien menunjukkan arah kenaikan tercepat fungsi pada titik tertentu. Arah negatif gradien menunjukkan arah penurunan tercepat untuk perubahan infinitesimal dalam geometri Euclidean.

11.2 Titik Kritis

Titik kritis fungsi terdiferensialkan dapat ditemukan dengan mencari titik ketika gradien nol.

\[ \nabla f(\mathbf{x})=\mathbf{0}. \]

Titik kritis dapat berupa minimum lokal, maksimum lokal, atau titik pelana. Oleh karena itu, gradien nol saja belum menjamin bahwa suatu titik merupakan minimum.

11.3 Optimisasi

Optimisasi adalah proses mencari nilai variabel yang meminimalkan atau memaksimalkan suatu fungsi tujuan. Dalam machine learning, fungsi tujuan biasanya menyatakan kerugian atau kesalahan prediksi.

Contoh fungsi kuadrat:

\[ f(x)=(x-3)^2+2. \]

Turunannya adalah

\[ f'(x)=2(x-3). \]

Dengan menetapkan \(f'(x)=0\), diperoleh \(x=3\). Karena koefisien kuadratnya positif, titik tersebut merupakan minimum global dengan \(f(3)=2\).

11.4 Gradient Descent

Gradient descent merupakan algoritma iteratif untuk mencari minimum fungsi dengan memperbarui parameter ke arah negatif gradien.

\[ \boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t -\eta\nabla J(\boldsymbol{\theta}_t), \]

dengan \(\eta\) sebagai learning rate dan \(J\) sebagai fungsi kerugian.

11.5 Implementasi Gradient Descent

def f(x):
    return (x - 3)**2 + 2

def grad_f(x):
    return 2 * (x - 3)

x = 0.0
learning_rate = 0.1

for _ in range(100):
    x = x - learning_rate * grad_f(x)

print("Titik minimum hampiran:", x)
print("Nilai fungsi:", f(x))

Dengan learning rate yang sesuai, iterasi bergerak mendekati \(x=3\). Kecepatan konvergensi bergantung pada bentuk fungsi, nilai learning rate, dan titik awal.

11.6 Peran Optimisasi dalam Machine Learning

  • Regresi linear: meminimalkan kesalahan prediksi.
  • Regresi logistik: meminimalkan fungsi kerugian klasifikasi.
  • Jaringan saraf: memperbarui bobot dan bias melalui gradien.
  • Regularisasi: mengendalikan kompleksitas model melalui tambahan penalti.

Contoh Soal

Tentukan titik minimum fungsi \(f(x,y)=x^2+2y^2-4x+8y+10\).

Penyelesaian:

\[ \frac{\partial f}{\partial x}=2x-4=0 \Longrightarrow x=2. \]

\[ \frac{\partial f}{\partial y}=4y+8=0 \Longrightarrow y=-2. \]

Kedua koefisien kuadrat positif sehingga fungsi mencapai minimum global pada \((2,-2)\). Nilai minimumnya adalah

\[ f(2,-2)=4+8-8-16+10=-2. \]

12. Norm, Jarak, dan Similaritas

12.1 Norma Vektor

Norma adalah ukuran besar atau panjang suatu vektor. Norma sering digunakan untuk mengukur besar parameter, menghitung jarak, dan membentuk penalti regularisasi.

12.2 Norma L1

Norma L1 adalah jumlah nilai mutlak seluruh komponen.

\[ \|\mathbf{x}\|_1=\sum_{i=1}^{n}|x_i|. \]

12.3 Norma L2

Norma L2 merupakan akar dari jumlah kuadrat komponen.

\[ \|\mathbf{x}\|_2= \sqrt{\sum_{i=1}^{n}x_i^2}. \]

12.4 Jarak Euclidean

Jarak Euclidean antara dua vektor mengukur panjang garis lurus yang menghubungkan kedua titik.

\[ d(\mathbf{x},\mathbf{y}) = \sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}. \]

12.5 Jarak Manhattan

Jarak Manhattan menjumlahkan selisih absolut masing-masing komponen.

\[ d_1(\mathbf{x},\mathbf{y}) =\sum_{i=1}^{n}|x_i-y_i|. \]

12.6 Cosine Similarity

Cosine similarity mengukur kesamaan arah dua vektor melalui kosinus sudut di antara keduanya.

\[ \operatorname{cos}(\mathbf{x},\mathbf{y}) = \frac{\mathbf{x}\cdot\mathbf{y}} {\|\mathbf{x}\|_2\|\mathbf{y}\|_2}. \]

Jika kedua vektor tak nol, nilainya berada pada interval \([-1,1]\). Nilai mendekati 1 menunjukkan arah yang mirip, nilai 0 menunjukkan ortogonal, dan nilai mendekati -1 menunjukkan arah berlawanan. Pada data fitur nonnegatif, nilai cosine similarity umumnya berada pada interval \([0,1]\).

Cosine similarity tidak terdefinisi jika salah satu vektor adalah vektor nol karena normanya nol.

12.7 Contoh Perhitungan

Diberikan vektor

\[ \mathbf{x}=(1,2),\qquad \mathbf{y}=(4,6). \]

Norma L1 dari \(\mathbf{x}\):

\[ \|\mathbf{x}\|_1=|1|+|2|=3. \]

Norma L2 dari \(\mathbf{x}\):

\[ \|\mathbf{x}\|_2=\sqrt{1^2+2^2}=\sqrt5. \]

Jarak Euclidean:

\[ d(\mathbf{x},\mathbf{y}) =\sqrt{(1-4)^2+(2-6)^2}=5. \]

Jarak Manhattan:

\[ d_1(\mathbf{x},\mathbf{y})=3+4=7. \]

Cosine similarity:

\[ \frac{1(4)+2(6)} {\sqrt5\sqrt{52}} =\frac{16}{\sqrt{260}} \approx0.9923. \]

12.8 Implementasi Python

import numpy as np

x = np.array([1, 2], dtype=float)
y = np.array([4, 6], dtype=float)

norm_l1 = np.linalg.norm(x, ord=1)
norm_l2 = np.linalg.norm(x)

jarak_euclidean = np.linalg.norm(x - y)
jarak_manhattan = np.sum(np.abs(x - y))

penyebut = np.linalg.norm(x) * np.linalg.norm(y)
cosine_similarity = np.dot(x, y) / penyebut

print("Norma L1:", norm_l1)
print("Norma L2:", norm_l2)
print("Jarak Euclidean:", jarak_euclidean)
print("Jarak Manhattan:", jarak_manhattan)
print("Cosine similarity:", cosine_similarity)

12.9 Penerapan dalam Data Science

  • K-Nearest Neighbors: menggunakan jarak untuk mencari observasi terdekat.
  • Clustering: menggunakan ukuran jarak untuk mengelompokkan data.
  • Sistem rekomendasi: menggunakan cosine similarity untuk membandingkan profil atau preferensi.
  • Regularisasi: norma L1 dan L2 digunakan untuk mengendalikan besarnya parameter model.
  • Pencarian dokumen: cosine similarity dapat membandingkan representasi vektor dokumen.

Sebelum menghitung jarak pada fitur dengan satuan atau rentang yang berbeda, pertimbangkan standardisasi atau normalisasi. Tanpa penyesuaian, fitur berskala besar dapat mendominasi ukuran jarak.

Contoh Soal

Hitung jarak Euclidean dan Manhattan antara \(\mathbf{a}=(2,3,4)\) dan \(\mathbf{b}=(5,1,4)\).

Penyelesaian:

\[ d_E=\sqrt{(2-5)^2+(3-1)^2+(4-4)^2} =\sqrt{13}. \]

\[ d_M=|2-5|+|3-1|+|4-4|=5. \]
