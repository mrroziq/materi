Time Series Analysis

Time series analysis atau analisis runtun waktu adalah metode untuk memahami data yang diamati secara berurutan berdasarkan waktu. Analisis ini digunakan untuk menemukan pola historis dan memperkirakan nilai pada masa depan, seperti penjualan, harga, permintaan barang, curah hujan, dan jumlah pelanggan.

1. Konsep Data Runtun Waktu

Data runtun waktu (time series) merupakan kumpulan observasi yang diurutkan berdasarkan waktu. Setiap observasi memiliki waktu pengamatan dan nilai yang dicatat.

Contoh data penjualan harian:

import pandas as pd

df = pd.DataFrame({
    "tanggal": [
        "2026-01-01",
        "2026-01-02",
        "2026-01-03",
        "2026-01-04",
        "2026-01-05"
    ],
    "penjualan": [120, 135, 128, 150, 160]
})

df["tanggal"] = pd.to_datetime(df["tanggal"])
df = df.sort_values("tanggal")
df = df.set_index("tanggal")

print(df)

Indeks waktu membantu kita mengakses observasi berdasarkan tanggal dan melakukan operasi temporal, seperti menghitung rata-rata bergerak atau mengelompokkan data berdasarkan bulan.

Data runtun waktu dapat memiliki frekuensi pengamatan yang berbeda:

  • Per detik atau per menit, misalnya data sensor.
  • Per jam, misalnya konsumsi listrik.
  • Per hari, misalnya penjualan harian.
  • Per bulan atau per tahun, misalnya inflasi dan pertumbuhan ekonomi.

Frekuensi dan keteraturan pengamatan perlu diperhatikan. Data harian yang memiliki tanggal hilang tidak selalu dapat langsung diperlakukan sebagai data dengan jarak waktu seragam.

2. Trend, Seasonality, dan Residual

Data runtun waktu sering terdiri atas beberapa pola yang dapat membantu menjelaskan perubahan nilai dari waktu ke waktu.

  • Trend: kecenderungan jangka panjang, seperti kenaikan penjualan selama beberapa tahun.
  • Seasonality: pola yang berulang pada periode tetap, seperti peningkatan penjualan menjelang hari raya.
  • Residual: bagian yang tersisa setelah komponen pola yang dimodelkan diperhitungkan.

Dekomposisi Aditif

Dalam model aditif, data dinyatakan sebagai:

\[ Y_t=T_t+S_t+R_t \]

Di sini, \(Y_t\) adalah observasi, \(T_t\) adalah trend, \(S_t\) adalah komponen musiman, dan \(R_t\) adalah residual.

Dekomposisi Multiplikatif

Jika besarnya fluktuasi musiman bergantung pada tingkat trend, model multiplikatif dapat digunakan:

\[ Y_t=T_tS_tR_t \]

Model multiplikatif biasanya memerlukan nilai positif dan sesuai ketika perubahan musiman cenderung proporsional terhadap tingkat data.

Contoh dekomposisi dengan Python

import pandas as pd
from statsmodels.tsa.seasonal import seasonal_decompose

data = pd.Series(
    [10, 12, 15, 18, 14, 16, 20, 23,
     17, 19, 24, 27, 21, 23, 28, 31],
    index=pd.date_range(
        "2025-01-01",
        periods=16,
        freq="MS"
    )
)

hasil = seasonal_decompose(
    data,
    model="additive",
    period=4
)

print("Trend:")
print(hasil.trend)

print("Seasonality:")
print(hasil.seasonal)

print("Residual:")
print(hasil.resid)

Parameter period=4 menyatakan bahwa satu siklus terdiri atas empat observasi. Nilai ini hanya contoh untuk data dengan pola empat langkah; untuk data bulanan dengan pola tahunan, periode yang lazim adalah 12. Dekomposisi klasik umumnya memerlukan setidaknya dua siklus lengkap.

3. Stationarity

Stasioneritas (stationarity) adalah sifat suatu proses runtun waktu yang karakteristik statistiknya tidak berubah terhadap waktu. Dalam stasioneritas lemah, rata-rata dan varians konstan, serta kovarians antara dua observasi hanya bergantung pada jarak waktu keduanya.

Secara sederhana, syarat stasioneritas lemah mencakup:

\[ E(Y_t)=\mu \] \[ \operatorname{Var}(Y_t)=\sigma^2 \] \[ \operatorname{Cov}(Y_t,Y_{t-k})=\gamma_k \]

Trend yang kuat atau perubahan varians dapat menunjukkan bahwa data tidak stasioner. Banyak model klasik, seperti ARMA, mengasumsikan proses yang stasioner, sedangkan ARIMA menggunakan differencing untuk membantu menangani nonstasioneritas tertentu.

Differencing

Differencing pertama menghitung selisih antara observasi saat ini dan observasi sebelumnya:

\[ \Delta Y_t=Y_t-Y_{t-1} \] 
import pandas as pd

data = pd.Series([100, 105, 111, 118, 126])

selisih = data.diff()

print("Data awal:")
print(data)

print("Differencing pertama:")
print(selisih)

Differencing dapat membantu menghilangkan trend tertentu, tetapi tidak menjamin data menjadi stasioner. Terlalu banyak differencing juga dapat menghilangkan informasi atau menambah kompleksitas model.

Uji Augmented Dickey-Fuller (ADF)

from statsmodels.tsa.stattools import adfuller

hasil = adfuller(data.dropna())

print("ADF statistic:", hasil[0])
print("p-value:", hasil[1])

if hasil[1] < 0.05:
    print("Tolak hipotesis unit root pada taraf 5%")
else:
    print("Belum cukup bukti untuk menolak hipotesis unit root")

Hipotesis nol pada uji ADF menyatakan adanya unit root dalam spesifikasi pengujian. Nilai p yang kecil memberikan bukti untuk menolak hipotesis nol, tetapi interpretasinya tetap bergantung pada spesifikasi uji dan karakteristik data.

4. Autocorrelation dan Partial Autocorrelation

Autocorrelation mengukur hubungan antara suatu observasi dan nilai masa lalunya. Partial autocorrelation mengukur hubungan pada lag tertentu setelah pengaruh lag di antaranya diperhitungkan.

Autocorrelation Function (ACF)

ACF pada lag \(k\) mengukur korelasi antara \(Y_t\) dan \(Y_{t-k}\). Secara konseptual:

\[ \rho_k=\operatorname{Corr}(Y_t,Y_{t-k}) \]

Partial Autocorrelation Function (PACF)

PACF mengukur hubungan langsung antara \(Y_t\) dan \(Y_{t-k}\) setelah hubungan linear melalui lag 1 hingga \(k-1\) diperhitungkan.

ACF dan PACF membantu memahami struktur ketergantungan temporal dan menentukan kandidat orde model ARIMA. Keduanya bukan aturan otomatis: pemilihan model tetap perlu mempertimbangkan diagnostik residual dan performa prediksi di luar sampel. 

import matplotlib.pyplot as plt
from statsmodels.graphics.tsaplots import (
    plot_acf,
    plot_pacf
)

fig, axes = plt.subplots(2, 1, figsize=(10, 7))

plot_acf(data, lags=10, ax=axes[0])
axes[0].set_title("Autocorrelation Function (ACF)")

plot_pacf(data, lags=6, ax=axes[1], method="ywm")
axes[1].set_title("Partial Autocorrelation Function (PACF)")

plt.tight_layout()
plt.show()

Gunakan jumlah lag yang sesuai dengan panjang data. Untuk PACF, jumlah lag juga harus cukup kecil agar estimasi tetap layak.

5. Moving Average

Moving average atau rata-rata bergerak menghitung rata-rata dari sejumlah observasi terakhir. Teknik ini membantu menghaluskan fluktuasi jangka pendek dan memperlihatkan pola umum.

Rata-rata bergerak dengan jendela \(m\) dapat ditulis sebagai:

\[ MA_t=\frac{1}{m}\sum_{i=0}^{m-1}Y_{t-i} \]

Misalnya, moving average tiga hari menggunakan nilai hari ini dan dua hari sebelumnya untuk menghitung rata-rata. 

import pandas as pd

df = pd.DataFrame({
    "penjualan": [100, 120, 110, 140, 150, 130, 160]
})

df["MA_3"] = df["penjualan"].rolling(
    window=3
).mean()

print(df)

Secara default, hasil moving average baru tersedia setelah jendela berisi tiga observasi lengkap. Moving average biasa digunakan untuk smoothing dan analisis trend; ia tidak otomatis merupakan model forecasting yang memprediksi nilai masa depan.

6. Exponential Smoothing

Exponential smoothing memberikan bobot lebih besar pada observasi terbaru dan bobot yang semakin kecil pada observasi lama. Metode ini berguna untuk membuat prediksi berdasarkan pola historis.

Simple Exponential Smoothing

\[ \ell_t=\alpha Y_t+(1-\alpha)\ell_{t-1} \]

Di sini, \(\ell_t\) merupakan estimasi level, sedangkan \(\alpha\) adalah parameter smoothing dengan nilai antara 0 dan 1. Nilai \(\alpha\) yang lebih besar memberi bobot lebih tinggi pada observasi terbaru.

Holt dan Holt-Winters

  • Holt's method: memperhitungkan level dan trend.
  • Holt-Winters: memperhitungkan level, trend, dan seasonality.
from statsmodels.tsa.holtwinters import (
    SimpleExpSmoothing,
    ExponentialSmoothing
)
import pandas as pd

data = pd.Series(
    [100, 105, 110, 108, 115, 120, 125, 123, 130, 135],
    index=pd.date_range(
        "2026-01-01",
        periods=10,
        freq="D"
    )
)

model = SimpleExpSmoothing(
    data,
    initialization_method="estimated"
).fit()

prediksi = model.forecast(steps=3)

print("Prediksi tiga hari berikutnya:")
print(prediksi)

Simple exponential smoothing cocok untuk data yang terutama memiliki level tanpa trend atau pola musiman yang jelas. Untuk data dengan trend atau seasonality, pertimbangkan metode Holt atau Holt-Winters.

7. ARIMA dan SARIMA

ARIMA merupakan singkatan dari Autoregressive Integrated Moving Average. Model ini menggabungkan ketergantungan pada nilai masa lalu, differencing, dan struktur error masa lalu.

Model ARIMA ditandai dengan tiga parameter:

  • p: orde autoregressive (AR).
  • d: jumlah differencing nonmusiman.
  • q: orde moving average (MA) dalam struktur model error.

Notasi modelnya adalah:

\[ ARIMA(p,d,q) \]

SARIMA memperluas ARIMA dengan komponen musiman. Notasinya dapat ditulis:

\[ SARIMA(p,d,q)(P,D,Q)_s \]

Parameter \(P,D,Q\) merupakan orde komponen musiman dan \(s\) adalah panjang periode musiman, misalnya 12 untuk data bulanan dengan pola tahunan.

Contoh ARIMA

import pandas as pd
from statsmodels.tsa.arima.model import ARIMA

data = pd.Series(
    [100, 105, 103, 110, 115, 112, 120, 125, 123, 130,
     135, 133, 140, 145, 143, 150, 155, 153, 160, 165],
    index=pd.date_range(
        "2025-01-01",
        periods=20,
        freq="D"
    )
)

train = data.iloc[:-4]
test = data.iloc[-4:]

model = ARIMA(
    train,
    order=(1, 1, 1)
).fit()

prediksi = model.forecast(steps=len(test))

hasil = pd.DataFrame({
    "aktual": test,
    "prediksi": prediksi
})

print(hasil)

Contoh SARIMA

from statsmodels.tsa.statespace.sarimax import SARIMAX

model = SARIMAX(
    train,
    order=(1, 1, 1),
    seasonal_order=(1, 1, 1, 7),
    enforce_stationarity=False,
    enforce_invertibility=False
).fit(disp=False)

prediksi = model.forecast(steps=len(test))

print(prediksi)

Contoh SARIMA menggunakan periode musiman 7, yang dapat relevan untuk pola mingguan pada data harian. Orde dan periode tersebut hanya contoh; pemilihan model harus disesuaikan dengan frekuensi, panjang data, pola musiman, serta evaluasi pada data yang tidak digunakan untuk melatih model.

8. Forecasting dengan Machine Learning

Forecasting tidak hanya dapat dilakukan dengan model statistik. Algoritma machine learning seperti regresi, Random Forest, dan gradient boosting juga dapat digunakan dengan mengubah data runtun waktu menjadi fitur prediktif.

Contoh fitur untuk memprediksi penjualan berikutnya:

  • Lag features: penjualan satu, dua, atau tujuh hari sebelumnya.
  • Rolling statistics: rata-rata atau standar deviasi beberapa hari terakhir.
  • Calendar features: hari dalam minggu, bulan, dan penanda hari libur.

Jika target adalah penjualan hari \(t\), fitur lag satu hari adalah \(Y_{t-1}\). Fitur ini hanya valid jika nilainya sudah tersedia saat prediksi dibuat. 

import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

df = pd.DataFrame({
    "tanggal": pd.date_range(
        "2025-01-01",
        periods=100,
        freq="D"
    ),
    "penjualan": [
        100 + i * 2 + (i % 7) * 5
        for i in range(100)
    ]
})

df = df.sort_values("tanggal").copy()

df["lag_1"] = df["penjualan"].shift(1)
df["lag_7"] = df["penjualan"].shift(7)
df["rolling_mean_7"] = (
    df["penjualan"]
    .shift(1)
    .rolling(window=7)
    .mean()
)
df["hari_dalam_minggu"] = df["tanggal"].dt.dayofweek

data_model = df.dropna().copy()

fitur = [
    "lag_1",
    "lag_7",
    "rolling_mean_7",
    "hari_dalam_minggu"
]

X = data_model[fitur]
y = data_model["penjualan"]

batas = int(len(data_model) * 0.8)

X_train = X.iloc[:batas]
X_test = X.iloc[batas:]
y_train = y.iloc[:batas]
y_test = y.iloc[batas:]

model = RandomForestRegressor(
    n_estimators=200,
    random_state=42
)

model.fit(X_train, y_train)
prediksi = model.predict(X_test)

print("MAE:", mean_absolute_error(y_test, prediksi))

Contoh tersebut memakai pembagian berdasarkan waktu, bukan pengacakan. Rolling mean dihitung menggunakan observasi sebelumnya karena data digeser dengan shift(1) sebelum perhitungan jendela.

Perlu diperhatikan bahwa kode ini mengevaluasi prediksi satu langkah ke depan dengan nilai aktual sebelumnya tersedia untuk membentuk fitur pada setiap baris pengujian. Untuk meramalkan banyak langkah ke depan tanpa observasi aktual baru, fitur lag harus diperbarui secara rekursif menggunakan prediksi sebelumnya atau memakai strategi multi-step lain.

9. Evaluasi Prediksi Temporal

Model forecasting perlu dievaluasi menggunakan data yang berada setelah periode pelatihan. Pembagian acak biasa dapat memberikan hasil yang menyesatkan karena informasi masa depan berpotensi masuk ke data latih.

Mean Absolute Error (MAE)

\[ MAE=\frac{1}{n}\sum_{t=1}^{n}|y_t-\hat{y}_t| \]

MAE mengukur rata-rata selisih absolut antara nilai aktual dan prediksi.

Root Mean Squared Error (RMSE)

\[ RMSE= \sqrt{\frac{1}{n}\sum_{t=1}^{n}(y_t-\hat{y}_t)^2} \]

RMSE memberi penalti lebih besar pada kesalahan yang besar dibandingkan MAE. Keduanya memiliki satuan yang sama dengan target.

Mean Absolute Percentage Error (MAPE)

\[ MAPE=\frac{100\%}{n} \sum_{t=1}^{n} \left|\frac{y_t-\hat{y}_t}{y_t}\right| \]

MAPE bermasalah ketika nilai aktual nol atau sangat dekat dengan nol. Untuk data seperti itu, pertimbangkan metrik alternatif. 

from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error
)
import numpy as np

aktual = np.array([100, 120, 130, 125, 150])
prediksi = np.array([110, 115, 128, 130, 145])

mae = mean_absolute_error(aktual, prediksi)
rmse = np.sqrt(mean_squared_error(aktual, prediksi))

print("MAE:", mae)
print("RMSE:", rmse)

Walk-forward validation

Walk-forward validation mengevaluasi model secara berurutan. Model dilatih pada data yang tersedia, memprediksi periode berikutnya, lalu jendela pelatihan diperluas atau digeser sesuai rancangan evaluasi.

Metode ini meniru penggunaan model di dunia nyata dengan lebih baik daripada pembagian data acak untuk forecasting temporal.

10. Pencegahan Kebocoran Data Masa Depan

Data leakage temporal terjadi ketika model menggunakan informasi yang belum tersedia pada saat prediksi dilakukan. Kebocoran ini dapat membuat hasil evaluasi terlihat bagus, tetapi gagal ketika diterapkan pada data masa depan.

Contoh kebocoran temporal

  • Menggunakan penjualan hari berikutnya sebagai fitur untuk memprediksi hari ini.
  • Menghitung rata-rata seluruh periode, termasuk periode uji, sebelum membentuk fitur.
  • Mengacak data waktu sebelum memisahkan data latih dan uji.
  • Menggunakan nilai akhir suatu periode yang belum diketahui pada saat prediksi.
  • Mengisi nilai yang hilang dengan informasi masa depan pada skenario prediksi real-time.

Prinsip pencegahan

  1. Urutkan data berdasarkan waktu.
  2. Pisahkan data latih dan uji berdasarkan batas waktu yang jelas.
  3. Gunakan hanya fitur yang sudah tersedia pada waktu prediksi.
  4. Hitung rolling feature dari masa lalu, bukan dari observasi masa depan.
  5. Lakukan tuning model dengan validasi temporal, bukan menggunakan data uji akhir.
  6. Untuk forecasting banyak langkah, pastikan strategi pembentukan fitur sesuai dengan informasi yang akan tersedia pada setiap horizon.

Contoh pemisahan data berdasarkan waktu: 

import pandas as pd

df = df.sort_values("tanggal").reset_index(drop=True)

batas_train = "2025-10-31"
batas_validasi = "2025-11-30"

train = df[df["tanggal"] <= batas_train]

validasi = df[
    (df["tanggal"] > batas_train) &
    (df["tanggal"] <= batas_validasi)
]

test = df[df["tanggal"] > batas_validasi]

print("Data train:", len(train))
print("Data validasi:", len(validasi))
print("Data test:", len(test))

Pastikan kolom tanggal bertipe datetime sebelum menjalankan perbandingan tanggal. Batas waktu di atas hanya contoh dan harus disesuaikan dengan cakupan dataset.

Ringkasan

  • Data runtun waktu terdiri atas observasi yang diurutkan berdasarkan waktu.
  • Trend, seasonality, dan residual membantu menjelaskan pola data.
  • Stasioneritas berkaitan dengan kestabilan karakteristik statistik suatu proses.
  • ACF dan PACF membantu memahami hubungan antarobservasi pada lag yang berbeda.
  • Moving average menghaluskan data, sedangkan exponential smoothing menggunakan bobot yang menurun untuk observasi lama.
  • ARIMA dan SARIMA merupakan model statistik untuk pola temporal nonmusiman dan musiman.
  • Machine learning dapat melakukan forecasting menggunakan lag, rolling statistics, dan fitur kalender.
  • Evaluasi temporal harus mempertahankan urutan waktu dan meniru kondisi prediksi nyata.
  • Data leakage masa depan harus dicegah sejak tahap pembentukan fitur hingga evaluasi.
